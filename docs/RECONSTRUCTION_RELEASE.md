# Granger-OSINT — Master Reconstruction

Проверка Windows x64, 30–31 октября 2026 года. Это отчёт о фактических результатах;
модельная гипотеза, успешно выполненный запрос и подтверждённая локация различаются.

## A. GEOINT

В существующий ToolRegistry/AgentRunner добавлен `image_understand`. Florence-2-base-ft
в отдельном offline CPU-процессе получает реальные пиксели: detailed caption, dense
region captions и phrase grounding. Закреплены MIT-веса, revision, размеры и SHA-256;
remote Python code не исполняется. Модель использует прежние изолированные CPU
dependencies, без установки ML в основное окружение приложения.
Описание и области — оценки модели, не проверенные детекции. Отдельно выполняются
настоящие EXIF и OCR; отсутствие GPS не подменяется отсутствием проверки.

GeoCLIP и Waypoint возвращают координаты, исходные оценки и разброс сэмплов.
Это некалиброванные гипотезы. Изменение seed не считается независимым подтверждением.
Точное повторение изображения/эффективных параметров/manifest читает сохранённое
наблюдение текущего расследования с исходным временем и provenance; новый inference
не запускается. Все новые пробы остаются в первичных evidence.

`geoint_research` получает кандидаты из этих результатов и признаки сцены, выполняет
ограниченные обратное геокодирование, поиск ориентиров и мультиязычные запросы.
Используются Nominatim, Overpass, Wikipedia, Wikimedia Commons и Panoramax.
Выполняются реальные загрузка доступных сравнительных снимков, локальное описание
эталонов и DISK/LightGlue matching. Фото, автор/производитель, лицензия, дата,
координаты архива и происхождение сохраняются. Координата эталона не приписывается
исходному снимку. Совпадения повторяющихся окон/фасадов не доказывают одно место.

Без персонального ключа реально получены Nominatim-результаты, Panoramax-фото и часть
Commons-фото. Доступ неоднороден: были 403, некорректные ответы, недоступные robots,
тайм-ауты Overpass/Wikipedia и отсутствие фотографий. Запреты не обходились.
OSM-карта показывает настоящие тайлы, атрибуцию и разные маркеры кандидатов/эталонов.
Галерея использует локальные пиксели, side-by-side и точки измеренного matching.

Google Vision Web Detection, Yandex SearchByImage/Search API и Mapillary — optional
официальные API с отдельными защищёнными credentials. Эти ключи не настроены:
положительные live-тесты не заявляются. Загрузка пользовательского оригинала в
reverse image API требует отдельного подтверждения. Во всех выполненных здесь
сценариях загрузок исходного изображения в облако было ноль.

Проверено семь классов на пяти реальных лицензированных исходных фотографиях;
преобразования явно перечислены, это не семь независимых accuracy samples.

## B. Гермиона и аналитический движок

Второго агента/чата нет. Существующий AgentRunner выполняет сбор, нормализацию,
локальные расчёты/корреляцию и отдельный итоговый анализ в том же investigation ID.
Чат, карта, граф, дерево и evidence используют один сохранённый набор данных.

Прежний `no_progress` переходил к списку первых evidence без языковой аналитики.
Теперь остановка сбора завершает исследовательскую фазу и запускает tool-free SSE
с рассчитанными фактами и ограничениями. Если провайдер недоступен, остаётся
содержательный локальный factual report. Стоп сохраняет полученные сведения и
написанную часть ответа; явное продолжение использует checkpoint.

У анализа отдельные настройки: 65536 output tokens/300 секунд по умолчанию.
Расход сохраняется в общей usage-истории, но не уменьшает бюджет сбора. Тайм-аут
исследовательского запроса не обрывает итоговый SSE. При `finish_reason=length`
сохраняется часть и продолжается тот же документ. Реальный тест: четыре `length`,
затем `stop`, 5 частей, 15133 символа, 506 text events, 43.464 секунды,
60116 reported tokens; секрет/видимые raw evidence IDs отсутствуют.

Исправлены дополнительные причины потери анализа: обрезка structured JSON на
50000 символах, неверное второе system message после backend tool result,
отсутствие explicit EXIF/OCR outcomes в финальном контексте. Факты помечены как
недоверенные данные, а не инструкции. Изображения/base64 не отправляются DeepSeek.
Ссылки evidence остаются открываемыми, видимые подписи — человеческие.

Уже готовый отчёт не генерируется повторно при обычном восстановлении. Новый
вопрос по выбранному узлу/связи сохраняет ID; локальное объяснение не запускает
новые внешние инструменты. Системный характер — точная и вдумчивая Гермиона,
ИИ-ассистент без утверждений о реальной личности и без постоянных ролевых сцен.

## C. Blockchain

Оригинал Gansar в `C:/Users/Admin/Desktop/crypto_osint` не изменялся. Используются
существующие адаптер, DTO, защищённое хранилище и read-only source modules.
Финансовые расчёты выполняются Decimal по всему DTO до пагинации evidence.
TON raw/bounceable/non-bounceable формы объединяются только с проверкой CRC,
workchain и test-only domain. Равный тикер без contract ID не объединяет активы.

Реальный deep-запрос пользовательского TON-адреса: 302 уникальных события,
137 входящих, 81 исходящее, 41 self, 43 с неустановленным направлением;
36 контрагентов, период 2025-10-19 — 2026-10-17. 10 коллекторов, 54 HTTP-запроса,
75.901 секунды; статус partial, были внешние 404/429/500/502.
Это наблюдаемая выборка, не полная история.

По известным суммам TON: 717.048086871 получено / 716.693790270 отправлено;
jetton: 268.883398 / 268.883398. Суммы разных контрактов не складываются.
Крупнейшее отдельное событие 176.873598 TON отличается от совокупного оборота
контрагента 402.861724246 TON. Есть направления/активы каждого контрагента,
дни/часы активности, крупнейшие события и два повторяющихся точных паттерна:
13 событий по 0.000000001 TON, медианный интервал 718714 секунд;
4 события по 0.300000000 TON, медианный интервал 0 секунд из совпадающих timestamp.
Эти расчёты не доказывают назначение адреса, транзитную функцию или намерения.

Шесть NFT объединены между DTO-разделами без повторных активов из-за формы TON.
Известный нулевой jetton-баланс не стирается неполным вторым наблюдением.
Коллекции/имена/метки — утверждения источника; текущее владение не подтверждается
одними metadata. Сомнительный unscoped scraped `@media` отделён как требующий
проверки CSS-подобный маркер, исходное evidence сохранено.
В графе 259 событий с endpoints образуют 42 flow groups; 43 unresolved события
не превращаются в выдуманные направленные связи.

ENS/Web3, отдельный NFT branch, cached assets, выбранный контрагент, объяснение
связи и restart прошли настоящие EXE-сценарии. В identity-only quick-запросе
получено vitalik.eth, reverse_valid=true; отдельное подтверждение владения
отсутствует. Не заявляются установление личности и полный финансовый поиск.
Новый quick-запрос TON в чате дал 137 событий: это другая частичная выборка,
не повторение deep-выборки из 302. Поздние NFT/cached DTO больше не подменяют
полную историю меньшим подмножеством: выбирается максимальное unique-event coverage,
а не последний результат и не количество повторных строк.

Пример смысла итогового анализа: почти равные наблюдаемые TON-поступления и
списания сами по себе не доказывают транзитный кошелёк. 43 события с неизвестным
направлением исключаются из направленных оборотов; крупнейшая операция отличается
от суммы операций с контрагентом. Назначение регулярных микропереводов неизвестно.

## D. Граф и медиа

Изменены существующие `InvestigationWorkspace`, `InvestigationCanvas`, graph-model,
graph-geometry и worker; добавлены GeoInvestigation и backend presentation/tiles.
Canvas2D отображает типизированные карточки, источник/сеть, потоки, счётчики,
настоящие thumbnails и различимые отношения. Tree имеет отдельные уровни.
Inspector скрывается, меняет ширину, показывает поля, источники и provenance.

Более 20 второстепенных контрагентов и большие наборы страниц/публикаций объединяются
в обратимые presentation groups. Это не общий владелец. В stress-1000 сохранены
1000 содержательных объектов и 5000 observed anchor relations; вместе с source/group
metadata — 2010 сущностей и 8004 отношений. Обзор показывает цель и пять групп,
поиск — нужные объекты и соседей. Не заявляется одновременная читаемость 1000 подписей.

Новые карточки не перекрывают сохранённые. Раскрытие выбранного flow показывает
только его операции и компактно пересчитывает незакреплённые позиции; pins остаются.
Встречные потоки, параллельные активы и self loops имеют общую геометрию рисования
и hit testing. Бюджеты отображения не удаляют первичные evidence.

PageParser сохраняет content_region/selector/method. Служебные anchors, navigation,
footer, support/status и media hosts не становятся авторскими claims по одному
body hash. Реальное чтение `github.com/solvnox`: 62 navigation entries в metadata,
три содержательные ссылки (два Telegram URL и репозиторий), без reporting abuse edge.
Каждое отношение содержит наблюдаемое поле/текст, источник, метод, время и статус.

В последнем EXE paint одного кадра: 20 карточек — 4.8 мс; сгруппированный stress-1000
(6 видимых карточек) — 1.4 мс; TON overview (20 карточек) — 4.4 мс; GEOINT с тремя
изображениями — 1.5 мс. Это отдельные замеры Canvas2D, не end-to-end latency и не
доказательство стабильного FPS либо ускорения всего приложения.
