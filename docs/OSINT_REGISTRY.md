# Исполняемый реестр и проверенные интеграции — 2026-10-29

Реестр расширяет `agent_tools.py`; центральный agent loop не превращает текст модели в код. Каждый инструмент имеет строгую схему аргументов, манифест, readiness, отмену/тайм-аут и нормализованное evidence. `tool_manifest.py` описывает входы, права, сеть, API/CLI, документацию и версию. Модель получает компактный набор схем по задаче; полная история и результаты сохраняются отдельно. GEOINT attachment_id разрешается только для выбранных пользователем файлов текущей задачи и восстанавливается из её зашифрованного checkpoint.

Статус `live_verified` в интерфейсе относится к собственному успешному выполнению адаптера в текущем процессе. Публичные QA-отчёты не подставляются в runtime как будто запрос уже выполнен пользователем. Поэтому чистая offline-проверка корректно имеет `verified_execution: 0`. Наличие локального CLI не подтверждает доступ всех его сайтов.

Существующие `domain_lookup` и `ip_lookup` повторно выполнены реально: example.org через DNS/RDAP и 1.1.1.1 через RIPEstat завершились complete. Maigret, Blackbird, Social Analyzer, Snoop, Holehe, PhoneInfoga, Wayback, Gansar, Telegram, VK и Instagram сохранены. Их прежние проверки и ограничения не выдаются за новые live-результаты.

## OSINT4ALL и кандидаты

Проверялся именно [предоставленный каталог](https://start.me/p/L1rEYQ/osint4all). HTTP403/Cloudflare challenge и ноль строк у web-reader не позволили получить его коллекцию. Из этой страницы извлечено **0** кандидатов; одноимённые страницы с другими ID не использованы вместо неё. Ограничения не обходились.

Девять отдельно исследованных записей основаны на официальных источниках: Google Lens, Yandex Images, закрытый Bing Visual Search API, TinEye, GeoNames, Mapillary, LeakCheck, URLhaus, ThreatFox. Они обозначены `catalog_only`, не имеют схем исполнения и не могут быть вызваны агентом. Lens/Yandex/TinEye доступны как ручной переход по явному действию; фотография не загружается автоматически. Для закрытого Bing нет перехода как к работающей интеграции.

Наличие [LeakCheck Public API](https://docs.leakcheck.io/overview) не означает интеграцию или разрешение получать сырые секреты. Его API не реализован здесь. Для GeoNames нужен собственный username; demo-аккаунт не использовался. Mapillary, URLhaus и ThreatFox требуют собственные данные доступа/условия провайдера. Void не добавлен: конкретный сервис и его официальный API не идентифицированы из запроса.

Цель 100–120 источников и20–30 персональных подключений трактуется как масштабируемость: каталог постраничный, схемы выбираются по задаче, источники виртуализированы; не заявляется наличие120 готовых интеграций. Установленные пользователем старые подключения продолжают использовать свои отдельные настройки. Новый ключ VirusTotal имеет отдельный сервис и выдаётся только этому адаптеру.

Первичные документы: [GitHub REST](https://docs.github.com/en/rest/repos/repos#get-a-repository), [Feodo dataset](https://feodotracker.abuse.ch/blocklist/), [VirusTotal file report](https://docs.virustotal.com/reference/file-info), [Nominatim usage policy](https://operations.osmfoundation.org/policies/nominatim/), [GeoNames](https://www.geonames.org/export/web-services.html). Остальные точные ссылки хранятся в манифестах и каталоге.
