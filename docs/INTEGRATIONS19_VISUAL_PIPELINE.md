# Sequential local visual GEOINT

`grangerpet.visual_models.pipeline` exposes `INPUT_SCHEMA` and `execute(args, settings, store, cancel_event=None, deadline=None, on_result=None)`. It uses the existing adapters in this order: image metadata, requested and available local OCR, selected `geoclip_predict` / `waypoint_predict` methods (default both), and optional ShadowFinder geometry only when explicit `shadow` parameters were supplied. It does not install models, access the network, infer a time or shadow measurement from an image, or create a second execution framework. The caller checks attachment scope and persists records in the existing evidence store.

Each returned raw observation is emitted with `on_result(record)` immediately after its stage, before checking cancellation again. Metadata therefore survives a later cancellation or model error. The envelope retains completed rows and returns `cancelled` or `timeout` when interrupted; otherwise any unavailable or failed requested stage produces `partial` if observations exist, or `error` if none exist. Unexpected stage failures expose a fixed error code rather than exception text. Model failures produce no invented predictions.

Metadata, OCR, model hypotheses, optional measured-shadow results and the computed coordinate comparison remain separate evidence records. The comparison uses actual valid returned coordinates, including EXIF GPS at 0°,0° when present, compares GPS to each bounded candidate and compares the first candidate of the two models. Invalid and missing coordinates are omitted, never replaced with 0°,0°. Distances use the haversine formula with mean Earth radius 6371.0088 km. A separation above 100 km sets `screening_distance_only`; it is a review threshold and does not establish which observation, if any, is wrong. EXIF is editable and unauthenticated, model scores are uncalibrated, and the two models are not independent evidence.
