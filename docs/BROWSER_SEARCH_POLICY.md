# Публичные поисковые формы

Разрешённый POST-поиск задаётся списком конкретных адресов и полей в browser_policy.py. В текущем списке Europe PMC searchPOST и NCBI esearch. Форма должна находиться на том же origin. Перед отправкой программа сравнивает её параметры с введённой поисковой строкой и проверяет небольшие фиксированные значения формата, базы и размера выдачи.

Запрос выполняется через существующий прокси с проверкой публичного DNS/IP и TLS. Проверяются robots, размер и тип ответа. Содержимое результата открывается для DOM-проверки с ограничивающей CSP. Авторизация и cookies браузерных профилей в запрос не передаются.

Контроль Europe PMC вернул HTTP 200, JSON и одну запись для строки open science. Эта проверка выполнила реальный POST через прокси. Выбор и заполнение такой формы на внешнем сайте в этом контроле не проверялись. Схемы подмены endpoint, origin, поисковой строки, скрытых полей, кодировки и размера выдачи проверены fixtures.

Полный браузерный контроль отдельной GET-формы прошёл на scrapethissite.com. Выполнены ввод, отправка, переход на вторую страницу, чтение таблицы и OCR скриншота. После отмены запрос завершился за 1,15 секунды. Проверка процессов подтвердила завершение собственных дочерних процессов. При подсчёте учитывается время выхода Windows-процесса, поскольку его завершённый объект ещё может возвращать счётчики по открытому handle.
