# GEOINT — источники, рельеф и проверка по фотографиям

2 ноября 2026 года две установленные CPU-модели обработали четыре фотографии с координатами камеры из архива Panoramax. Для каждой фотографии проверен SHA-256, исправлена ориентация и сформирован PNG из пикселей без имени места и EXIF. Расстояния ниже измерены по сфере от первого кандидата модели до координат снимка в каталоге. Геодезическая проверка координат каталога отсутствует.

У трёх новых источников кэш успешных запросов действует 24 часа в процессе приложения. Ответы 403/429 включают задержку перед следующим обращением. В данных сохраняются время получения, URL и SHA-256 ответа.

Для горной сцены Granger строит грубый профиль горизонта по 32 направлениям на трёх дальностях и выделяет границу неба по пикселям. Он сравнивает форму контура с 96 окнами предполагаемого направления и поля зрения. Облака, кроны и пропуски между точками DEM ограничивают этот метод. При недостаточном контуре результат явно помечается как недоступный.

Контроль на снимке из Шамони даёт полезную отрицательную проверку. Для специально предложенных Медеу и Доломитов нормированная ошибка формы составила 1,245 и 1,234. Близость показателей не позволяет выбрать место съёмки. У Медеу загрузить подходящее фото не удалось. В итальянской ветви получены Panoramax и снимок Италии с орбиты. После проверки пикселей у орбитального снимка отрицательная оценка соответствия. Такой объект сохраняется среди противоречий и исключается из галереи совпадений.

В карточках координаты гипотезы округлены, а оригинальные значения доступны в доказательствах. Сводка Florence на русском описывает признаки, распознанные словарём. Оригинальная английская подпись сохраняется для проверки. Полный перевод произвольных редких объектов словарём не покрыт.
