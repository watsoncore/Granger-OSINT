
Результат: **166 из 166 проверок пройдены**. Это source build с настоящими production `PetWindow`, `OsintPanel`, `DesktopSurface`, WebChannel и собранным React. Не проверка финального упакованного EXE.

Использован изолированный APPDATA и пустой переносимый encrypted vault с уникальным тестовым credential namespace. Реальные ключи не читаются, генерация/API не вызываются, пользовательский профиль не открывается.

## Геометрия

Проверены логические размеры окна 1280×720, 1366×768, 1600×900, 1920×1080, 760×560 при WebEngine zoom 80%, 100%, 125%, 150%. Большие окна — виртуальные viewport тесты; они выравниваются правым краем по текущему экрану, чтобы нативный Pet оставался в реальной видимой части. Это не заявление о физических разрешениях монитора. Системные параметры DPI не изменялись; фактический DPR записан в JSON.

Для каждой комбинации проверены:

- единственный настоящий native Pet целиком находится внутри точного DOM dock, переведённого через zoom в координаты Qt;
- opaque alpha bounds оставляют прозрачный запас до всех краёв, включая голову и обувь;
- `settings.size` и сохранённая настройка остаются 195, временное уменьшение применяется только к `_display_size`;
- нет горизонтального overflow и дублирующихся dock-компонентов;
- геометрия нативного dock соответствует фактическому DOM, без расширения поверх функциональных элементов.

Дополнительно проверены четыре темы, maximize/restore, minimize/restore, сворачивание панели с явной кнопкой восстановления, отсутствие выдуманного dock после сворачивания, возврат к размеру desktop companion после скрытия workspace, остановленный cursor timer при выключенной реакции и ровно одно окно `DesktopPet`.

## Снимки

Скрипт сохраняет собственные Qt widget captures отдельно:

- `*-workspace.png` — содержимое окна workspace;
- `*-pet.png` — действительное независимое окно персонажа с alpha.

Независимое нативное окно Pet не включается в `QWidget.grab()` workspace. Снимки не склеиваются в якобы общий screenshot. Геометрическая связь доказывается записанными координатами и проверкой `dock.contains(pet.frameGeometry())`.

Визуально просмотрены снимки Pet при 760×560/150%, белая тема Pet и белый workspace. Исходная фигура, одежда, волосы и спрайты сохранены, голова и обувь не обрезаны.

Startup до готового workspace в этом source run: **2595.49 ms**. Сопоставимого нового baseline для этой команды нет; показатель не объявляется улучшением скорости.
