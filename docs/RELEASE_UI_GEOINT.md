## B. UI и доказательства

Квадрат вместо оконного символа устраняется удалением зависимости от Unicode-глифа: Qt-кнопки рисуют SVG через QSvgRenderer, frontend использует SVG. У закрытия, minimize, maximize/restore согласованные линии, palette, hover/pressed/focus. Проверены native SVG и настоящий frontend.

Причина пропадания персонажа подтверждена кодом: native Pet размером до 219px не помещался в DOM dock, после чего подавлялся. Старый метод дополнительно расширял dock до 240×219 даже при свёрнутой панели. Теперь учитывается только реальный DOM rectangle с zoom, без выдуманного fallback; `_display_size` временно подстраивается под него. Сохранённый desktop `settings.size` остаётся отдельным. Есть явная кнопка скрытия/восстановления панели.

Проверены пять логических размеров окна (1920×1080,1600×900,1366×768,1280×720,760×560), zoom80/100/125/150%, maximize/minimize/restore, четыре темы и полнота alpha-границ головы/обуви. Это 166 source-проверок с настоящим PetWindow. Большие viewport были виртуальными окнами, а не заменой монитора. Физическое Windows DPI100/150/200% **не проверено**; настройки ОС не менялись. Фактический DPR записан в отчёте.

Карточки используют общую grid-компоновку, minmax(0,1fr), одинаковые интервалы и нижние actions; длинные описания не обрезаются индивидуальными костылями. Каталог постраничный (24 записи), источники виртуализируются при количестве>40, чат сохраняет прежнюю виртуализацию>100. В source UI проверены 1000 сообщений и 120 источников; в DOM оставались 9 сообщений и 4 источника в проверенном viewport.

Источники текущей задачи имеют поиск, фильтры, группировку, выдержку, URL и переход к цитирующему ответу. Отдельный `task_sources` не смешивает счётчик с чужими задачами. Сниппет/JS-shell/ошибка не объявляются прочитанной страницей. Локальные image-результаты различают отсутствие GPS, повреждённые GPS-поля и невозможность прочитать метаданные, показывают размер, hash, OCR-области и confidence; полные исходные сведения доступны по evidence.

Удалены декоративные подписи «ПЕРСОНАЛЬНАЯ OSINT-СРЕДА», «ВАША ГЕРМИОНА» и нижняя версия лаунчера. Название приложения сохранено. Навигация/функции не удалены. Четыре semantic theme: тёмная, чёрная, белая, монохромная. Выбор сохраняется в настройках; начальная тема внедряется до React render, native background согласован. Лаунчер получает изменение через своё существующее обновление состояния, без нового polling-цикла.

Реально используется локальный **Manrope Variable** с кириллицей и OFL, доступный до обновления; точное семейство на пользовательском референсе не заявляется. Найдены существующие пользовательские Hermione brand PNG/ICO/SVG; дополнительного навигационного icon pack не было. Для навигации сохранён Lucide SVG и централизованная карта, без фиктивных путей к отсутствующим файлам. Текущие бренд/персонаж включены в EXE.

Снимки выполняются средствами собственных Qt-окон. Native Pet — независимое окно и в QWidget.grab(workspace) не попадает; его PNG сохраняется отдельно. Они не склеивались в выдуманный screenshot. Ненадёжный захват Computer Use исключён из доказательств.

## C. Гермиона

Новый `CharacterController` объединяет логические события panel/desktop: сообщение, начало задачи, начало/результат/ошибка инструмента, ответ, отмена, idle/return и непрочитанное уведомление. 13 логических состояний: idle, listening, thinking, searching, reading, working, happy, shy, annoyed, resting, sleeping, notification, error. Чтение EXIF/OCR/evidence передаёт состояние reading, поиск — searching; настоящий агентный результат определяет завершение. Приостановленная задача не запускает happy-анимацию. Бездействие не перебивает активную работу. Это не 13 новых sprite sequences: shy/annoyed имеют fallback, отдельные кадры отсутствуют.

Продолжают работать существующие семь sprite sequences: idle, hover, happy, thinking, working, walk, error; дыхание/моргание, физика и локальные чтение/отдых/сон/пробуждение сохранены. Существующие реакции лица не заменены трансформацией всей головы. Отдельных новых кадров shy/annoyed и работы с ноутбуком нет: они прямо перечислены в `ASSET_GAPS`. Coding events — расширяемая точка подключения, coding agent/терминал не добавлены.

## D. GEOINT — фактический статус каждого инструмента

| Название | Реализация, вход → выход | Локальность / статус | Тест / ограничения |
| --- | --- | --- | --- |
| image_metadata | Pillow13: разрешённое JPEG/PNG/WebP → EXIF/GPS, размеры, SHA-256, dHash, средний цвет | Локальный; выполнен | Реальный GPS JPEG и PNG безGPS, повреждения, отмена; в EXE GPS51.5,-0.125 и no_gps_metadata. Подлинность EXIF не подтверждается |
| image_ocr | Tesseract5.5.3 + rus/eng → настоящий текст, bbox в пикселях после применения EXIF orientation, confidence | Локальный; выполнен | Русские/английские пиксели, timeout/cancel с завершением процесса; русский OCR также в EXE и через DeepSeek tool_calls |
| image_compare | dHash/Hamming + SHA-256 → похожие ранее выбранные локальные изображения | Локальный; выполнен | Реальное сравнение фикстур и дедупликация. Не распознаёт город/здание; максимум ограниченного набора кандидатов |
| map_wikimedia | MediaWiki API: latitude,longitude → до 20 геотегов медиа в 1 км | Внешний official API; выполнен | Реальный London-запрос вернул 20 записей. Требует подтверждения передачи координат, не проверяет совпадение пикселей |
| map_overpass | Ограниченный фиксированный Overpass query: координаты → до 20 туристических объектов в 500 м | Внешний; настроенный endpoint необходим | Unit/HTTP-тесты пройдены; live timeout, успех не объявлен |
| map_geocode | Nominatim client: публичный топоним → кандидаты с OSM-ссылками | Внешний; configuration_required по умолчанию | Unit/HTTP-тесты; live **не проверено**. Собственный/разрешённый endpoint, rate/cache/attribution; публичный сервер не вшит как неограниченный backend |

Покрытие метаданных ограничено выбранными EXIF-полями (включая GPS/высоту/дату/камеру/software/orientation), признаками ICC и ограниченными строками image.info. Полноценный разбор бинарных XMP/IPTC/MakerNotes **не реализован**. Это не полная экспертиза метаданных.

Обратный поиск: Lens/Yandex/TinEye — manual handoff по действию пользователя; автоматическая отправка фотографий отсутствует. Bing Search API отмечен закрытым. Коммерческий TinEye API/семантическое распознавание места/спутниковая аналитика **не реализованы**. CV-факты не выдаются за определение улицы.

Вложения проверяются по сигнатуре и декодированию, размеру и пикселям; сохраняются шифрованными, включая оригинальные байты. Имя — только подпись, модель не задаёт путь. Переиспользуются immutable-image cache и один OCR-процесс с OMP_THREAD_LIMIT=1; plaintext temporary image/TSV не создаются. Выбор файла не запускает внешние запросы.

Реальный gateway production-agent smoke: два модельных запроса, два tool_calls (metadata/OCR),6359 фактически отчётных токенов, завершённый ответ по надписи «МОСКВА УЛИЦА МИРА». Модель не получила фото, base64 preview или заранее заданное описание. Проверены восстановление attachment scope и компактная передача настоящих GPS/OCR-данных, а полное evidence сохраняется отдельно.

## F. Защита и миграция

Обнаружены WCM для коротких ключей и DPAPI для длинных сессий, истории, checkpoints и непрочитанных ID. Legacy evidence/Canvas были открытыми JSON/Markdown. Toast/ActionCenter/Microsoft cloud/телеметрия в активном пути не обнаружены; внутренние уведомления сохранены.

Новый контейнер: Argon2id64 МиБ/t3/p4, AES-256-GCM, случайная соль и nonce, аутентифицированная версия формата, случайный data key, atomic replace после fsync, проверяемые границы размера/KDF. Пароль вводится только в native dialog, не хранится рядом с ciphertext и не попадает в React/IPC/логи. После restart требуется unlock; смена пароля переворачивает обёртку data key, а не все артефакты. Нет plaintext fallback.

Миграция только по явному созданию пользователем: прочитать legacy, создать зашифрованные копии, повторно проверить, затем атомарно активировать vault. Отказы/повреждения не объявляются успехом. Оригиналы/WCM не удаляются. Legacy plaintext-копии Canvas/evidence поэтому остаются; автоматического заявления об их исчезновении нет. После активации обычные операции используют portable-data; Windows API нужны только для legacy migration. Явный экспорт пользователем остаётся обычным Markdown.

Проверены неверный пароль, restart, целостность, сбой записи/прерывание/восстановление миграции, синтетический настоящий WCM/DPAPI, отсутствие legacy, частичное повреждение, Canvas/evidence/unread/images и блокировка при активных заданиях. Формат переносим; фактический запуск приложения под другой ОС **не проверен**. Реальные пользовательские данные автоматически не переносились и не удалялись. Все новые функции проверялись в изолированных профилях.

## G. Проверки и производительность

Финальный полный Python: **818 passed, 1 skipped, 32 subtests**, 177.31 с. После него узкая правка typed-ошибок неверных координат проверена отдельным набором **66 passed** (14.84 с), а финальные manifest/GEOINT-контракты — **56 passed** (9.15 с); полный прогон не выдаётся за включающий добавленный после collection тест. Пропуск — необязательный живой Ollama без локального сервера. Frontend после правки размеров пустого composer: **78 tests / 11 files**. Исходные baseline:661/1skip/32subtests и 62frontend. Source UI52/52, native Pet166/166; реальные пиксельные GEOINT fixtures, schema/errors/cancel/readiness и защищённая миграция проверены отдельно.

Для CPU используется 100%=одно логическое ядро; машина имеет 12 логических процессоров. RSS суммирует shared pages несколько раз, private commit не называется private working set. GPU PDH allocations не являются доказательством физического VRAM/leak. Global GPU flags, драйверы и системные настройки не менялись.

Нативная нагрузка видимого длинного чата имеет существенный разброс. Сохранённый старый EXE дал 28.66% одного ядра в первом повторе и 6.20% в следующем; финальный новый EXE дал 34.07% и 6.19% при повторном запуске того же бинарника. Последние сравнения — по три trial по 6 секунд; первый старый repeat был одним trial. Причина разброса (включая состояние compositor/focus) не установлена. Эти наблюдения не доказывают ни устранение CPU-проблемы, ни её однозначную связь с новым кодом. Ни один прогон не скрыт. Прежние оптимизации виртуализации, событийного bridge и hidden page сохранены; forced Frozen не возвращается.
