## VK: безопасность и границы проверки

В активном адаптере токен передаётся только заголовком `Authorization: Bearer`, через HTTPS, без перенаправлений. Старый параметр `access_token`, добавляемый локальной библиотекой, удаляется из формы до создания HTTP-запроса. Имя хоста и маршрут фиксированы. Ключ хранится в Windows Credential Manager; React получает только признак наличия.

Нативное окно предупреждает: ранее опубликованный токен необходимо отозвать и перевыпустить. Токены из старых URL, переписки и примеров не использовались. Контролируемые HTTP-тесты проверяют настоящую сериализацию установленной vk_api, но не подменяют живой положительный тест сервиса. Удалённые, неизвестные и закрытые профили, неверные права, CAPTCHA и rate limits обрабатываются отдельно.

## Баланс шлюза

Пользователь явно предоставил `GET https://api.aikeysforyou.com/v1/balance`. Реальный запрос с уже сохранённым в Windows ключом вернул HTTP 200 и числовое `token_balance`. Без авторизации endpoint возвращает 401. Запрос не запускает генерацию.

Смысл единиц не подтверждён документацией поставщика. Приложение показывает исходное значение как «Единицы шлюза (token_balance)», без конвертации в токены модели, кредиты или валюту. Локальный usage остаётся отдельным фактическим счётчиком API. Кеш — 60 секунд, минимальный интервал ручного обновления — 10 секунд; ошибки сохраняют явно устаревший последний успешный остаток и не меняют статус чата. Числовой остаток аккаунта не включён в публикуемый отчёт.
