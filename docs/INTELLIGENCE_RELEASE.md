# Granger-OSINT — intelligence/research, 1 ноября 2026

## A. Фактическая архитектура и поставленные инструменты

Расширен существующий Python/Qt/WebChannel-проект, его ToolRegistry, AgentRunner,
нормализация evidence, graph, checkpoints и прежний чат. Второй движок/чат не
создавался. 51 →70 зарегистрированных операций;65 локально доступны без личных
ключей источников. Готовность runtime не означает доступность удалённого сайта.

Добавлены7 сетевых,3 Steam,8 браузерных операций и `wikidata_places`.
[Матрица13 поставленных проектов](validation/intelligence-v1/tool-matrix.json)
указывает entry points, лицензии, операции, зависимости, ключи, риски, изоляцию,
live-status и реальную доступность агенту. Полная интеграция всех репозиториев не
заявляется. Включён проверенный MIT-subset SteamRecon; токен-зависимые сборщики,
небезопасные entry points, неподтверждённые risk/identity scores и проекты без
установленной лицензии не импортированы в приложение. Независимые эквиваленты
DNS/RDAP/CT не называются интеграцией полного SpiderFoot/theHarvester.

## B. IP, домен, Steam и остальные источники

IP/CIDR/ASN/домен распознаются внутри обычного запроса. Чистый числовой IP не
передаётся обычному поиску статей. Пассивные ветки: authoritative RDAP через IANA
bootstrap, RIPE routing/ASN/history, PTR, Spamhaus DROP и прежний Feodo; DNS,
domain RDAP и CT. Кэш не выдаётся за независимое наблюдение. Ошибка одной ветки
не уничтожает остальные. Оператор сети, пользователь устройства и место съёмки
не отождествляются.

Live Googlebot IP66.249.67.41: ARIN сообщает Google LLC/GOOGLE, RIPE —
AS15169/66.249.64.0/20, PTR — crawl-66-249-67-41.googlebot.com. Отсутствие совпадения
в DROP/Feodo не означает безопасность. В реальном агентном прогоне6 новых
операций завершились,6 повторных запросов обслужены без новой сети.

Steam: нормализация SteamID64/SteamID2/SteamID3/vanity, публичный профиль,
опубликованные прежние имена и открытые ссылки друзей. Реальный контроль Robin:
разрешён SteamID, прочитаны profile/aliases/friends; выборка друзей ограничена20.
Никнеймы разных площадок не объединяются в одну личность. Cookies, частные поля
и Steam API key для этого subset не использованы.

Реальные агентные проверки IP, example.org, Steam и Telegram завершились.
У domain-history был тайм-аут, у отдельного web_read — блокировка; их не скрывали.
Длинный TON-контроль burn-адреса сохранил949 записей и104 checkpoints, но достиг
тестового лимита времени и вернул частичный результат. Это не полный успешный
TON-отчёт. Исходный Gansar не изменялся.
[Live receipts](validation/intelligence-v1/agent-live.json).

## C. GEOINT

Сохранены Florence, GeoCLIP, Waypoint, OSM/Overpass/Nominatim, Commons,
Panoramax, локальное сопоставление и существующие optional API.
Добавлен read-only Wikidata: поиск мест, земные координаты P625, ссылки P18,
фильтр расстояния; [лицензия структурированных данных CC0](https://www.wikidata.org/wiki/Wikidata:Licensing). Лицензия изображения
проверяется отдельно на его Commons file page.

Commons теперь объединяет геотеги с семантическим поиском даже при наличии
ближайших файлов. Ранг объясняется типом сцены, расхождением с крупной надписью,
слабым вкладом расстояния и распределением геометрических совпадений. Близкая
табличка не должна вытеснять вид башни. Кандидаты и основания сохраняются;
наличие reference photo не подтверждает место. Оценка — приоритет просмотра,
не географическая вероятность.

Live-контроли известных мест вернули5/6 Commons references; Wikidata —2 места.
Новый CPU-прогон3 разных контрольных фото выполнил обе географические модели и
Florence без передачи пикселей наружу. OCR недостаточно уверен, исследования
частичные, один достиг тайм-аута. Точные координаты не подтверждены; это не
accuracy benchmark. [Фото-прогон](validation/intelligence-v1/geoint-live.json),
[Commons](validation/intelligence-v1/commons-ranking-live.json),
[Wikidata](validation/intelligence-v1/wikidata-live.json).

Google/Yandex не объявлены бесплатным автоматически работающим reverse-search:
существующий официальный optional API требует собственных ключей и разрешения
передать изображение. Обход доступа и выдуманные совпадения не добавлялись.

## D. Настоящий Browser Agent

Отдельный Playwright/Edge worker: navigate, snapshot, GET-search type/click,
scroll, back, screenshot, close. Временный непостоянный context без пользовательских
cookies/профиля; Windows Job1536MiB, bounded pipes/network/timeouts. Это процессные
ограничения, не полноценная изоляция прав Windows.

Весь egress закреплён за публичным DNS-проверенным IP через собственный loopback
proxy. GET/HEAD, стандартные порты, robots.txt; private/mapped/local addresses,
POST, WebSocket, downloads, uploads, login/payment/unknown buttons отключены.
Проверка robots использует прямое соединение с этим proxy, без Windows proxy
bypass. TLS/hostname проверяются. Неудачная robots-проверка закрывает доступ.

Модель получает недоверенный DOM, таблицы/JSON-LD, актуальные element_id и
snapshot_id. Worker хранит Python ElementHandle и перепроверяет элемент перед
действием. Screenshot действительно получен от Edge, показан в прежнем чате и
доступен локальному OCR; текстовой модели не приписывается vision-доступ.
Есть остановка, освобождение собственного Job и очистка при смене беседы.

Реальный DeepSeek-прогон: публичная GET-форма → New → Search → прокрутка → ссылка
на страницу2 → таблица → screenshot/Tesseract →3 реальные строки в отчёте.
После сжатия состояния формы текущая карта элементов сохраняется. Навигация
сохраняет исходный transport URL: удаление завершающего `/` приводило на этом
сайте к перенаправлению HTTPS→HTTP и правильному fail-closed robots-отказу.
Этот дефект исправлен, а не обойдён.

## E. Контекст и checkpoints

Архив, рабочая память, беседа, расследование и browser session остаются разными
состояниями. Дружеский вопрос выбирает только разговорные turns, исключая старые
объекты и provider errors. Приветствие вместе с явной задачей остаётся задачей.
В полном архиве ничего не удаляется.

Новые факты отделены от технического продвижения формы/прокрутки; повторные
snapshot_id/скриншоты не считаются новыми доказательствами. Для браузерных
действий обновляются schemas и cache identity. Полные первичные записи остаются
доступны через evidence_get, в том числе после compaction/recovery.
1652 Python checks включают fixtures ошибок/восстановления; имитации не объявлены
live API. Длинная реальная TON-проверка частичная, но checkpoint/evidence сохранены.

## F. Гермиона

Уточнена системная инструкция: любознательность, точность, самостоятельное мнение,
уместная ирония, обычная русская речь без постоянных сцен и технического
самопредставления. Образ вымышленного персонажа не выдаётся за реального человека.
Запрещены выдуманные прошлые действия/личные воспоминания. На3 реальных дружеских
сообщения шлюз ответил без tools и без возврата к @solvnox/старой ошибке429.
Стиль LLM остаётся вероятностным, а не гарантированным сценарием каждой реплики.

## H. Производительность и надёжность

Playwright1.64.1 установлен отдельными official binary wheels в
`.toolenvs/research-browser`; использован уже установленный Edge, Chromium не
скачивался. Основной Python/Qt runtime не менялся. Перенос одного EXE на другую
машину не устанавливает этот дополнительный runtime или тяжёлые visual models.
Подготовка browser runtime: `scripts/setup_research_browser.py`.

Отдельный live browser контроль:13 собственных процессов, около705MiB суммарного
RSS, отмена1.142–1.202с, после неё0 оставшихся собственных процессов с проверкой
PID+birth time. Это разовые наблюдения, не фиксированная норма расхода.
API/инструменты выполняются асинхронно. Частичные данные сохраняются при отмене,
тайм-аутах и ошибках. 401/402/403/429/5xx, timeout и malformed responses проверены
fixtures; намеренные плохие ключи в реальный шлюз не отправлялись.

Холодный native запуск полного локального pipeline занял около113с. При
одновременном крупном backup-копировании один QA IPC-запрос превысил2.5с;
завершение тестового процесса также задержалось. Тестовый тайм-аут расширен;
отсутствие микролагов при любой нагрузке ОС не заявляется.

Повторный полный native-прогон завершился:53 checks, обе CPU-модели, русский OCR,
реальные EXIF/GPS,4 темы и restart/preservation шифрованных изображений.
Pipeline133.785с; запуск EXE10.752с. Через несколько секунд после инструментов
warm runtime занимал2.70GB RSS суммарно, CPU медиана0.71% всей машины за6 samples.
Это не длительный idle-замер. Сомнительный raw GPU PDH aggregate исключён из
публичного отчёта, а не выдан за расход памяти CPU-моделями.
[Native model/local receipt](validation/intelligence-v1/native-local-models.json).
