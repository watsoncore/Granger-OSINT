# Master Fix V2 — текущая проверка

Задание активно. Конечный EXE пока не обновлялся для V2; предыдущая проверенная
сборка сохранена. Новая работа не считается завершённой по числу операций/тестов.

## Воспроизведённые причины

- До исправления `investigation_requested('а этот IP 87.199.131.94?')` возвращал False,
  хотя центральный entity router правильно извлекает infrastructure_asset.
  Таким образом, обычный streaming chat запускается без tools.
- До исправления `is_social_turn('Герми, ты здесь?')` возвращал False; короткая кличка и вопрос
  о присутствии не включены в conversational boundary.
- Provider400/422 сейчас сворачивается в общее «отклонил параметры» без
  безопасной технической диагностики. Причина конкретного live-запроса ещё
  не установлена и не приписывается max_tokens или tool schema без ответа шлюза.

## Этап 3 — provider и набор инструментов

Набор ограничен 32 определениями с приоритетом текущей сущности и отдельным
поиском capabilities_find по настоящему реестру. Следующий шаг получает найденные
операции без снятия permissions. Изменение набора — прогресс планирования, не факт.
Диагностика HTTP отделена от local validation и не сохраняет переписку/ключи.
Runtime negotiation снимает только явно отвергнутый optional stream_options,
одним исправленным повтором; остальные параметры и tools не отключаются.
Контроль broad прошёл 5 HTTP 200 и сохранил 12 evidence; обычный вопрос о готовности
Steam вызвал реальный каталог. Намеренно неправильный messages дал проверенный
HTTP 400 с безопасным body receipt. 90 provider/protocol и 160 registry fixtures
прошли. Это source/live QA; финальная V2 EXE ещё не собрана.
