# Master Fix V2 — проверка поставки

Windows x64 EXE: 279228663 байта, SHA-256
`428f3d02060bf059573921c7d8e8cdd08cab11a70526cdbef4049473548d2077`.
Производственный код: `58a20ae267d10dd30bda8b110714c6a5c495c784`.
Позднейшие изменения относятся к проверкам и документации. Встроенный Python
совпал с исходниками по 154 модулям; frontend/resources — по 221 проверке.
Предыдущие EXE и ZIP сохраняются. Работа не объявляется полностью завершённой.

## Воспроизведённые причины и исправления

| Причина | Изменение и наблюдение |
|---|---|
| Короткий literal-IP выбирал обычный чат при правильно распознанной сущности | Общий entity router и target текущей беседы; оба IP и короткий вопрос о локации вызвали сетевые операции в EXE |
| Социальная реплика не отделялась от старой задачи | Границы для приветствия, «Отложим», новой беседы и нового изображения; native последовательность из восьми реплик прошла |
| Более 40 schemas отвергались локальным клиентом до HTTP | До 32 определений, реальный capabilities_find и найденные разрешённые операции на следующем шаге; broad control дал пять HTTP 200 и 12 evidence |
| Provider 400 терял диагностическую причину | Безопасные status/parameter/body hash; единственный исправленный повтор только для явно отвергнутого optional stream_options. Tools не отключаются |
| HTTP 200/JS-shell VK принимался за содержимое, TikTok путал video/profile ID | Отдельные публичные коллекторы, нормализация целей и наблюдаемые nullable поля; независимые HTML/render/archive статусы |
| Browser TLS verify 19 в frozen worker | Тот же проверяемый host CA bundle; TLS не отключается, runtime и Windows не меняются |
| Общий лимит 20 обрезал реальные предметы Steam | Сохранение bounded inventory до registry/runner/checkpoint, реальные item/media/category entities, компактный model context |
| RDAP country подменяла GeoIP, maintainer смешивался с оператором | Две отдельные оценки GeoIP, фактический интервал и содержащие CIDR, роли org/contact/RIR, дедуп BGP с provenance |
| Tree и Graph почти совпадали | Один основной родитель и ветви Tree; отдельная сеть дополнительных отношений Graph, bounded worker, раскрытие и раздельное сохранение позиций |
| GEOINT зависел от первого модельного региона и случайных фото | Независимые предложенные регионы, DEM/OHM/STAC, пиксельный контур и грубое DEM сравнение; отрицательные фото исключаются из галереи совпадений |
| Проверенное подключение становилось checking при каждом сообщении | Connected сохраняется во время асинхронного запроса, окончание/ошибки обновляют тот же AI state |

Исторический HTTP 400 именно для voin-cs.kz не воспроизведён. Установлена
отдельная local schema-limit ошибка. Намеренно неправильный messages дал
настоящий HTTP 400 с безопасным receipt; это разные случаи.

## Сохранность профиля — исключение

Baseline: 2026-11-02 06:40:53 UTC. Из 69 исходных файлов профиля 66 сохранили
SHA-256. Два отсутствующих файла — временные блокировки экземпляров. Один
именованный шифрованный диалог того же размера получил другие байты 13:12:33 UTC
(18:12:33 местного времени). Пользователь подтвердил, что приложение не трогал.
Причина не установлена; утверждать побайтовую сохранность всей истории нельзя.

Текущий шифрованный файл дополнительно сохранён в приватной ignored QA-папке.
Baseline содержит только хеши; точных исходных байтов нет. Более ранняя
существующая шифрованная копия содержит 60 сообщений: проверено наличие их
текстов в нынешних 117 сообщениях. Это другая, более ранняя копия, поэтому
отсутствие потерь относительно V2 baseline этим не доказано. Тексты не
печатались и не экспортировались. Текущий файл не откатывался/не перезаписывался.

## Проверки и ограничения доказательств

Конечный полный source прогон: 1755 passed, 1 skipped (Ollama), 32 subtests,
356,02 с, в отдельном APPDATA и namespace credentials. Frontend: 137 passed,
TypeScript passed; production build и packaged frontend совпали.
Результаты записаны в release-summary.

Текущий EXE: network/context 10 проверок, site/social 8, graph 34; 51 core
проверка local/OCR/EXIF/models/restart и 46 проверок трёх фотографий. Core subset
выделен из расширенного прогона, который затем не прошёл 8-sample benchmark;
его неудача сохранена отдельно. Конечный canonical EXE PE smoke: Launcher
11,383 с, Pet 12,395 с, оба exit 0, ограниченный PATH и isolated profile. Строго
различаются fixtures, live HTTP, source-native и frozen EXE. Ранние неудачные
прогоны не удалены и не засчитаны как успех. QA идёт последовательно: несколько
тяжёлых EXE одновременно давали IPC deadlines при нагрузке.

Дополнительный geographic QA при 8 сэмплах выявил пустой список Waypoint для
городского кадра при status completed. Первоначальное предположение о гонке
сохранения не подтвердилось. Тест фиксирует пустой список явно и повторяет
штатные 32 сэмпла; координаты не подставляются, runtime/модели не изменяются.
