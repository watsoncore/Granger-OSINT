# Автономный агент GrangerPet 2.5

Агент встроен в существующий Qt-чат. Спросите: «Найди публичные упоминания никнейма solvnox». Поисковые глаголы направляют запрос в агент; обычное приветствие остаётся быстрой перепиской. Продолжения «ещё», «подробнее», «сравни», «источник» используют текущий диалог и сохранённый реестр доказательств.

## Цикл и границы

`ChatWidget → UiJob → AgentRunner → DeepSeekClient.complete_turn → ToolRegistry → SourceAdapter.run → настоящий результат → роль tool → следующий ход модели`.

Модель видит каталог фактической готовности и JSON Schema только доступных инструментов. Файлы и названия классов сами по себе не означают готовность: исполняемые мосты проверяются импортом в своих окружениях. Холодное обнаружение ограничено 12 секундами, кэш — 45 секундами. Вызовы имеют разные имена и типы аргументов для никнейма, email, телефона, домена, IP, URL и блокчейн-адреса. Число результатов ограничено, дополнительные/неизвестные аргументы отклоняются. Shell, Python, PowerShell, eval, произвольное чтение файлов и команды модели не предоставляются.

По умолчанию: 6 ходов LLM, 8 вызовов, 2 одновременных инструмента, 120 секунд на расследование, 25 секунд на инструмент, 24 000 суммарных учитываемых токенов. Перед отправкой резервируется оценка входа и лимит выхода; при отсутствии usage резервируется весь лимит. Точный финальный счёт зависит от статистики шлюза. Инструментальный контекст — до 6 000 символов на ответ, общий контекст до 48 000, до 200 сохранённых находок. Один и тот же вызов повторно не выполняется. Целая связка assistant/tool удаляется при сокращении старого протокольного контекста; одиноких tool-сообщений нет.

Независимые вызовы выполняются параллельно. Каждый результат возвращается с исходным `tool_call_id`; зависимые шаги выполняются после получения настоящих ответов. Структурированный путь не исполняет текст модели. Неизвестный протокол не заменяется недоказанным JSON-парсером обычной переписки.

## Инструменты

| Имя | Настоящий путь и пределы |
|---|---|
| username_maigret / username_blackbird / username_social_analyzer | Существующие отдельные мосты поиска точного никнейма. Ограниченный набор публичных площадок; обнаружение профиля не доказывает владельца. |
| username_snoop | Только если прежняя локальная интеграция включена. В текущем профиле выключена. |
| email_holehe | Существующий ограниченный read-only набор; требуется явное согласие перед вызовом. Никаких сбросов пароля или рассылки. |
| phone_metadata | Прежний мост PhoneInfoga: формат и доступные метаданные, а не владелец номера или полный upstream-сканер. |
| blockchain_gansar | Существующий Gansar и его поддержанные сети/валидация, включая TON. Транзакции и наблюдения не подменяются выводами модели. |
| web_archive | Существующий Wayback-мост для публичного URL. |
| telegram_public / vk_public / instagram_public | Прежние адаптеры и авторизация, отдельное согласие. Отсутствие сессии явно недоступно; наличие сессии не гарантирует права. |
| web_search | Прежний настроенный Google CSE либо один обычный публичный запрос DuckDuckGo HTML без нового ключа. Реальные URL/заголовки/фрагменты, отказ при CAPTCHA/блокировке без обходов. |
| domain_lookup | Пассивные DNS A/MX/NS через фиксированный публичный DoH и RDAP для поддержанных .com/.net/.org. Не сканирование домена. |
| ip_lookup | Публичный ASN/префикс через RIPEstat; частные и служебные IP отклоняются. |
| evidence_get | Полная безопасная сохранённая находка текущего диалога по точному evidence_id; нового поиска нет. |

Публичные ограниченные проверки идут автоматически. Holehe и авторизованные источники требуют согласия в стандартном Qt-диалоге, по умолчанию отказ. Разрешение относится к конкретному вызову. Тайм-аут/отмена не выполняет оставшиеся шаги. Массовый обход источников, активные сканеры и отправка сообщений в реестр не входят.

## Доказательства и текущий интерфейс

Каждая находка имеет evidence_id, URL, инструмент, исходный запрос, UTC-время, статус источника и основание наблюдения. Точный ресурс устраняет повторы; никнейм не используется как ключ объединения людей. Противоречивые статусы сохраняются отдельными наблюдениями. Ссылки в итоговом ответе сверяются с реальными находками. Отдельно приложен формируемый кодом реестр проверяемых ссылок, а не только пересказ модели.

Все найденные тексты считаются недоверенными данными. Секретные поля, сессии, внутренние пути и точные значения используемых ключей исключаются до передачи/сохранения. reasoning_content нужен только для протокола DeepSeek и не появляется в UI/журналах. В найденной странице нельзя изменить список доступных функций или разрешить чувствительную операцию.

Полные безопасные нормализованные результаты хранятся отдельно от короткого модельного контекста в `%APPDATA%/GrangerPet/investigations/<id>.json`. Туда не записывается исходная переписка, заголовки HTTP или конфигурация. Частичные сведения сохраняются при отмене и сбое сети. Текущие находки также попадают в прежний виртуализированный список «Поиск», где доступны старые подробности и копирование. Ручной поиск не очищается автоматически агентом; его новое явное начало использует прежнее поведение.

Состояния выбора плана/анализа отображаются существующим thinking, проверки источников — working, завершение — happy, ошибка — error. Новых спрайтов нет. Обычная беседа использует SSE и обновляет один существующий пузырь, без пересоздания истории. Инструментальные сообщения принимаются целиком, чтобы не исполнять незавершённый JSON. Стоп в прежнем composer отменяет расследование; после отмены старые события не меняют новый диалог.
