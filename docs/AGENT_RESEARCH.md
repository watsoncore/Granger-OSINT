# Исследование архитектур OSINT-агентов

Исследовано 28 октября 2026 г.: GitHub Search, README, доступные исходники, документация и issues. Никакой исходный код этих проектов не переносился в новые модули GrangerPet; новые агентные модули написаны для существующих адаптеров. Установочные скрипты исследуемых репозиториев не выполнялись. Ключи и пользовательские конфигурации на GitHub не отправлялись.

| Первичный источник | Конкретный вывод для GrangerPet |
|---|---|
| [OpenOSINT/OpenOSINT](https://github.com/OpenOSINT/OpenOSINT), [метаданные MIT](https://github.com/OpenOSINT/OpenOSINT/blob/main/pyproject.toml) | Отдельный каталог разрешённых инструментов, пассивный режим, лимит вызовов, результат с именем источника. В GrangerPet функции выбираются из локального реестра, чувствительные операции требуют согласия. |
| [AXRoux/argus-os](https://github.com/AXRoux/argus-os) | Ограниченный цикл планирования, вызовов адаптеров и анализа; независимые проверки параллельны. Использован архитектурный принцип, не серверный код и не интерфейс Argus. Лицензия не использовалась как основание для переноса кода; прямое чтение raw LICENSE было недоступно. |
| [sherlock-project/sherlock](https://github.com/sherlock-project/sherlock), [исходник проверки](https://github.com/sherlock-project/sherlock/blob/master/sherlock_project/sherlock.py) | Проверка никнейма зависит от правил площадки, ошибка сети отличается от отсутствия профиля. Не добавлялся второй дублирующий движок: сохранены Maigret/Blackbird. |
| [soxoj/maigret](https://github.com/soxoj/maigret), [checking.py](https://github.com/soxoj/maigret/blob/main/maigret/checking.py) | Сохранена настоящая site-specific проверка CLAIMED/UNKNOWN существующего моста. Автообогащение, похожие имена, активация, обход защит и повторные запросы не включались. Локальная поставка Maigret имеет MIT LICENSE. |
| [megadose/holehe](https://github.com/megadose/holehe) | Возможности отдельных модулей различаются; название инструмента не доказывает безопасный способ проверки. Сохранён прежний ограниченный набор модулей, без восстановления пароля/рассылки. В агенте email-проверка дополнительно требует подтверждения. |
| [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph), [описание лимита шагов](https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/errors/GRAPH_RECURSION_LIMIT.mdx) | Явные пределы шагов и сохранение частичного состояния. Библиотека не добавлялась: Qt-проекту достаточно небольшого собственного контроллера. |
| [LangGraph issue 8516](https://github.com/langchain-ai/langgraph/issues/8516) | Сообщение об игнорировании ограничения параллельности в одном async-пути стало поводом проверить собственный лимит реально одновременно работающих задач; это сообщение issue, а не универсальный вывод о библиотеке. |
| [huggingface/smolagents](https://github.com/huggingface/smolagents), [Apache-2.0 LICENSE](https://github.com/huggingface/smolagents/blob/main/LICENSE) | Компактный агентный цикл и описания инструментов. Исполнение генерируемого Python не переносилось: GrangerPet принимает только JSON-аргументы зарегистрированных функций. |
| [deedy5/ddgs](https://github.com/deedy5/ddgs), [searxng/searxng](https://github.com/searxng/searxng) | Сопоставлены keyless-метапоиск и собственный сервер. SearXNG требует отдельного сервера; DDGS добавляет стек зависимостей. Для текущей поставки выбран существующий HTTPX и один обычный публичный HTML-запрос DuckDuckGo, с явной ошибкой при блокировке, без обходов. При настроенном Google CSE используется прежний разрешённый API. |
| [DeepSeek tool calls](https://api-docs.deepseek.com/guides/tool_calls/) | Ассистент возвращает структурированные вызовы; каждый результат связан через tool_call_id. reasoning_content при необходимости повторяется только внутри протокольной истории, не в UI/журнале доказательств. Реальная поддержка стороннего шлюза проверена отдельно. |

Новые runtime-зависимости не добавлены. Существующие сторонние инструменты остаются в своих изолированных окружениях и с прежними notices. Аналитические идеи выше реализованы собственным кодом, поэтому дополнительных фрагментов чужого кода и новых лицензионных обязательств от копирования нет. Фактические сетевые проверки и их ограничения перечислены в VALIDATION.md.
