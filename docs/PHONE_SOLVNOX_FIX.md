# Телефонная сцена Hermione / Solvnox

1 ноября 2026. Изменена только `phone_solvnox` и необходимые ей производные
рукава, кисти и телефон. Интерфейс, настройки размеров, DeepSeek, OSINT, GEOINT,
Gansar, другие персонажи и расписание автономии не изменены.

## Причина и исправление

Старая постановка соединяла универсальный прямой указательный палец, неподходящий
хват и непрозрачный корпус телефона. Проверка расстояния до условной грани
проходила, хотя касание видимого стекла и убедительное сгибание пальца отсутствовали.
Надписи фаз и движение предмета не доказывали, что персонаж печатает.

Теперь телефон имеет отдельный узкий косой ракурс с боковой гранью и небольшой
видимой полосой стекла, без подписи Solvnox. Он расположен сбоку ниже лица.
Правая согнутая рука поддерживает его снизу, большой палец перекрывает край;
левая имеет собственный рукав, локоть, манжету и согнутый указательный палец.
Фронтальная часть пальцев рисуется после телефона, остальные части кисти — до.
Это непересекающиеся участки одного рисунка, без удвоения прозрачности.

Постановка длится 13 секунд: извлечение из-за края мантии → чтение и улыбка →
четыре касания → пауза → два касания стирания → четыре касания с другим ритмом →
проверка → отдельное завершающее касание выше клавиатуры → лёгкий румянец →
убирание за край мантии → исходный idle. Это локальная сценка; сетевых сообщений нет.

`PhoneContact` явно описывает `phone_pose`, `phone_screen_geometry`,
`holding_hand_anchor`, `typing_hand_anchor`, `typing_fingertip`, `tap_target`.
Кончик берётся из метаданных нарисованной кисти и преобразуется тем же transform,
что её изображение. Во время нажатия он достигает стекла, при отводе проходит
около 8.7 logical px на размере 195. Телефон при наборе стабилен относительно
удерживающей кисти: набор не заменяется покачиванием предмета.

## Сохранение оригинала

Новая голова, лицо, волосы, глаза и neutral mouth не создавались. Все **80 ранее
существовавших art files**, включая master и семь atlas, сохранены побайтно.
13 защищённых исходников проходят identity gate; neutral имеет **0 pixel/alpha
changes**, исходный atlas frame0 на 256 px совпадает точно. **217 контрольных
кадров остальных сцен** совпадают побайтно с состоянием до правки.

Голова наклоняется целиком. Только исходная текстура зрачков смещается внутри
прежних фиксированных масок; phone-only вертикальная амплитуда увеличена до
2.5 source px для взгляда вниз. Контуры глаз, их размеры, посадка и alpha
не меняются. Blink возвращает исходные pixels. Начальная и конечная позы
телефонной сцены выбирают буквальный исходный neutral.

## Проверка и визуальные доказательства

[Все клипы, кадры и сравнение лица](validation/phone-solvnox-v1/PREVIEWS.md).

- Полный backend: **1539 passed, 1 skipped** (optional Ollama), **32 subtests**,
  294.12 s. Целевой gate: **120 passed**; результаты пересекаются, не суммируются.
- Frozen EXE: **131 Python modules / 221 resources**, точное соответствие
  исходникам и ресурсам, включая прежний frontend.
- Четыре полных нативных клипа окончательного EXE: widget 100/160/195 и
  Windows compositor поверх принадлежащего тесту текста на 195. **1268 PNG**,
  примерно **23.81 fps**, каждый клип доходит до завершения.
- **11/11** касаний найдены в настоящих native PNG; в контрольном hover нет
  pixels пальца у цели. Проверяется видимый палец на стекле, а не один флаг фазы.
  Подсчёт pixels — вспомогательная проверка; раскадровка и полные клипы приложены.
- **15/15 native runtime checks**: активный набор, hover, drag up/down, реакции
  на рывки, три прежних таймера, exit0 без orphan, повторный запуск в исходном idle.
- Cold launcher/pet: **11.411 / 11.574 s**, exit0, restricted PATH без Python,
  отдельные свежие профили. Телефон без записи экрана: **23.74 render fps**,
  CPU машины **1.93%**, private commit дерева **242.37 MB**, tick p95 **8.77 ms**.
  После 25 быстрых смен сцены осталось три таймера; private commit
  **242376704 → 245530624 bytes**. Это короткий замер, не доказательство отсутствия
  любой долговременной утечки.
- Source production previews: **100, 160, 195, 256 px**. Нативный запрос 256
  ограничивается существующей настройкой до **195**; он не засчитывается как
  нативная проверка 256. Диапазон настроек не изменялся.
- **54/54** файла профиля пользователя неизменны, проверены отдельно от QA-профилей;
  имена, содержимое, ciphertext и checkpoints в evidence не публикуются.

Разработческие прогоны сначала выявили неточный neutral на границе сцены:
последующая общая настройка `source_idle` перезаписывала выбор исходника.
Исправлен именно phone endpoint; окончательный полный прогон прошёл.
Первый runtime harness запускал следующую сцену до обработки mouse-leave:
добавлена пауза в тесте, runtime для этого не менялся. Ранние результаты
не выдаются за прошедшую проверку окончательной сборки.

## Поставка

Windows x64, `dist/Granger-OSINT.exe`, **279015421 bytes**.

SHA-256: `2f39ef873aae31c5040ec220e47bd4cca11f993dd98afbeeda3c545fc1a33d4b`.

Существующий desktop shortcut ведёт на этот путь. Предыдущие EXE/ZIP сохранены
в локальном `dist/archive`. Исходный ZIP содержит только исходники и явно
выбранные public evidence. Публикация — обычный commit/push в существующую
ветку `granger/chibi-reconstruction`; точный commit и remote status фиксируются
в `dist/git-publication.json`, хеши артефактов — в `dist/Granger-OSINT.release.json`.

Нативный 256 px, GPU-метрики и многодневная стабильность этой сценки не
заявляются. Исторические общие soak/интеграционные проверки предыдущего релиза
сохранены как история, а не представлены повторными измерениями этой сборки.
