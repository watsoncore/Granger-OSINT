# GEOINT: реальные локальные изображения и географические данные

Реализация находится в `grangerpet/geoint/images.py` и `mapping.py`. Это инструментальные операции backend, а не зрение текстовой модели. Импорт, EXIF, структурные признаки, сравнение и OCR не выполняют внешних запросов. Произвольного определения страны, города, улицы или здания по пикселям нет: `semantic_geolocation=unsupported_capability`.

## Изображения и защита

`AttachmentStore(root, seal=..., open_sealed=...)` требует провайдер шифрования разблокированного хранилища. Plaintext fallback отсутствует. Атомарно сохраняется зашифрованная запись с исходными байтами, заголовком, проверяемым SHA-256 и небольшим preview. Временный файл содержит только ciphertext. Идентификатор `img_<64 hex SHA-256>` проверяется полным регулярным выражением; имя исходного файла используется только как очищенная подпись. Произвольные пути модели не принимаются. Символические ссылки на файлы отвергаются.

JPEG, PNG, WebP проверяются по фактической сигнатуре и декодируются Pillow **13.0.0**. Расширение не считается доказательством формата. Максимум 20 МиБ, 24 млн пикселей, 16384 пикселя по стороне; анимационные файлы не принимаются. Повреждение и decompression bomb приводят к ошибке. Preview не содержит исходных EXIF. Исходник не перезаписывается. Повторные байты получают тот же идентификатор; повреждённый существующий ciphertext не маскируется успешной дедупликацией.

Метаданные и OCR, включая имена и надписи, являются недоверенными данными источника. Они не могут превращаться в инструкции агенту. Base64 preview предназначен только UI и не должен включаться в контекст модели.

## Контракты и фактические статусы

| Инструмент | Вход | Выход | Исполнение и тест | Ограничения |
|---|---|---|---|---|
| `image_metadata` | Локальный `attachment_id` | Размеры, формат, SHA-256, EXIF, GPS при наличии, 64-bit dHash, средний RGB | Локальный Pillow; реальные JPEG с заданным GPS и без GPS проверены | Подлинность EXIF не установлена; поддержанные поля EXIF, ограниченные текстовые chunks и факт ICC, без полного произвольного XMP/IPTC |
| `image_ocr` | `attachment_id`, `rus`/`eng` | Реальный текст Tesseract, word bounding boxes, confidence, длительность | Локальный Tesseract **5.5.3**, русский и английский реально распознаны из сгенерированных PNG | Нет семантической интерпретации объектов; OCR ошибается; отсутствие backend/model явно возвращает `not_installed`/`configuration_required` |
| `image_compare` | `attachment_id` | До 30 локальных кандидатов, расстояние dHash, точное совпадение байтов | Реально сравниваются локальные PNG и JPEG одного тестового рисунка | До 200 файлов по умолчанию; не внешний reverse search; близкий hash не доказывает один объект |
| `map_wikimedia` | `latitude,longitude` | До 20 геотегированных файлов Commons в радиусе 1000 м, URL и атрибуция | Официальный MediaWiki GeoData API; реальный запрос к публичному ориентиру Лондона вернул 20 записей | Изображения автоматически не скачиваются и визуально не сопоставляются; лицензия каждого файла находится на его странице |
| `map_overpass` | `latitude,longitude` | До 20 именованных `tourism=attraction` объектов в 500 м | Реализован фиксированный ограниченный Overpass QL; schema/error/cache unit checks пройдены | В приложении нужен разрешённый endpoint; реальный smoke публичного сервера завершился timeout, успешное внешнее выполнение **не подтверждено** |
| `map_geocode` | Публичный топоним до 300 символов | До 5 Nominatim-кандидатов | Реализован API-клиент, валидация и обработка ошибок | По умолчанию endpoint не задан; действующий операторский сервис **не проверен** |

`no_gps_metadata` возвращается явно, с `gps=null`. Некорректные GPS дают `invalid_gps_metadata`, а не `0,0`. Настоящее допустимое значение нулевых координат не запрещается. EXIF GPS — только наблюдение метаданных, не подтверждённое место съёмки.

OCR сначала применяет EXIF orientation, уменьшает длинные стороны до 3000 пикселей и переносит координаты word boxes в систему ориентированного исходника (`exif_oriented_original_pixels`). Сведения о системе координат возвращаются явно. Оригинал и его метаданные не передаются Tesseract через временный файл: PNG без EXIF и TSV проходят через анонимные stdin/stdout pipes. Ограничен размер TSV, число слов и число потоков OpenMP. Отмена и timeout завершают только созданный этим вызовом процесс, затем ожидают его завершения. Реальные cancel/timeout тесты проверяют отсутствие оставшегося дочернего процесса.

Повторный metadata analysis использует ограниченный cache неизменяемых результатов. Перед возвратом cache хранилище снова проверяет доступность дешифрования и целостность записи. Нет фонового запуска анализа или постоянного polling.

## Сетевые правила

Географические координаты могут быть чувствительными; внешняя передача должна соответствовать пользовательскому scope и разрешениям текущего агента. Выбор файла сам по себе ничего не отправляет наружу. Публичные Nominatim и Overpass не настроены как универсальный backend приложения. Для использования требуется явный операторский endpoint, соответствующий политике сервиса.

Клиент использует узнаваемый User-Agent с URL проекта, одну общую последовательную очередь фактических запросов в процессе, интервал минимум 1,1 с, cache до 128 запросов на час, максимум 1 МиБ ответа и ограниченный timeout. Нет автодополнения, массовых сеток координат, произвольного Overpass-кода модели, автоматического переключения зеркал и обхода HTTP 403. При HTTP 429 учитывается Retry-After, автоматические повторы отсутствуют. OSM-результаты содержат атрибуцию и ODbL-ссылку. API error не превращается в положительное совпадение.

Основные документы, проверенные при реализации:

- [Pillow Image API и декодирование](https://pillow.readthedocs.io/en/stable/reference/Image.html).
- [Tesseract CLI, языки и TSV](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html).
- [Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/): ограниченная инфраструктура, идентификация приложения, cache и ограничения на generic geocoding/LLM generated platforms. Публичный endpoint не подключён автоматически.
- [Overpass: квоты, 429 и ограничения ресурсов](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html).
- [MediaWiki GeoData API](https://www.mediawiki.org/wiki/Extension:GeoData#API).

## Обратный поиск

Ни один reverse-search сервис не получает файл автоматически. `reverse_search_providers()` возвращает каталог честных режимов, а не результаты анализа:

- Google Lens — `manual_handoff`, [официальная ручная загрузка](https://support.google.com/websearch/answer/1325808).
- Яндекс Картинки — `manual_handoff`, [официальный интерфейс похожих изображений](https://yandex.com/support/images/en/similar); программный reverse-image API не подтверждён.
- Bing Visual Search API — `unavailable`: [прежние Bing Search APIs выведены из эксплуатации 11.08.2025](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement).
- TinEye — `manual_handoff`; [коммерческий API существует](https://services.tineye.com/TinEyeAPI), но отдельный доступ и фактическое выполнение не проверены.

## Воспроизводимый локальный OCR

`resources/ocr/provenance.json` фиксирует SHA-256 архивов официального MSYS2 HTTPS-репозитория, версии 49 runtime packages, SHA-256 каждого включённого файла и commit языковых моделей `tesseract-ocr/tessdata_fast`. Из архивов выбраны только 40 PE-файлов, действительно импортируемых `tesseract.exe`, языковые данные rus/eng, конфигурация TSV и 60 файлов лицензий. Общий размер — **39 415 796 байт**. Самый большой файл около 5,5 МБ.

Подготовка без установки в ОС:

```powershell
.\.venv\Scripts\python.exe scripts/setup_geoint_ocr.py
```

При наличии manifest команда воспроизводит закреплённые версии и проверяет hashes; `--refresh` явно обновляет набор из текущего repository database. Ни installer, ни package manager, ни код продавца API не запускаются; реестр, службы и глобальный PATH не меняются. [MSYS2 Tesseract package](https://packages.msys2.org/packages/mingw-w64-ucrt-x86_64-tesseract-ocr) — источник бинарников; [официальный Tesseract tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) — источник моделей Apache-2.0. Windows-бинарник поставлен сторонним packager MSYS2, а не выдаётся за официальный Windows installer Tesseract.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_geoint_images.py tests/test_geoint_mapping.py -q
.\.venv\Scripts\python.exe scripts/qa_geoint.py
```

На момент проверки **43 tests passed**: фактические декодирование и GPS EXIF, отсутствие GPS, плохой GPS, повреждённые EXIF, три формата, ограничение размера и pixels, traversal, дедупликация, повреждение ciphertext, незавершённая атомарная запись, повторный analysis без decode, блокировка vault, реальный русский и английский OCR, реальные cancel/timeout Tesseract, валидация mapping-контрактов, HTTP 401/403/429/5xx, timeout, invalid JSON, cache и отмена до сети.

HTTP unit tests используют явно обозначенный MockTransport и **не** считаются live-проверкой. Отдельный `output/geoint-engine/mapping-live.json` содержит реальный Commons success и реальный Overpass timeout. `local-smoke.json` содержит фактические результаты синтетических локальных fixtures, без чтения пользовательских фотографий, профилей или ключей. Приёмка интеграции с чатом, реестром и packaged EXE выполняется отдельно в основном release audit; эти проверки не подменяются наличием модулей.
