# V11: инвентаризация новых источников

Полные backend-прогоны включали 101 новый адаптер. Два прогона дали по 100 свежих непустых ответов. В более позднем прогоне успешно отработали 99 адаптеров, Finna вернул HTTP 403, а портал открытых данных Канады завершился по таймауту. Оба ранее проходили проверку. Для всех 101 адаптера есть парсерные fixtures и автоматизированные тесты.

Один API с несколькими endpoint не увеличивает счётчик. Эти записи не включают сайты Maigret, операции Gansar, поисковые workflow, дополнительные экземпляры Mastodon/Discourse или повторные бренды Open Food Facts. Национальные порталы — отдельные каталоги разных издателей. В них обрабатываются метаданные наборов, без скачивания содержимого. Реестры пакетов — метаданные, без скачивания или исполнения кода.

Каждый адаптер использует фиксированный HTTPS origin, allowlist полей, публичный read-only API без ключа, общие DNS/SSRF/redirect/byte/rate/concurrency ограничения. Лицензии программного сервера не переобъявляются лицензиями пользовательского контента. Условия источника и права отдельных записей сохраняются в limitations; весь сторонний контент не распространяется как часть приложения. API, квоты и условия могут измениться после даты проверки.

Состояние в каталоге остаётся `implemented_unverified` до выполнения в текущем окружении. Release receipt — отдельное свидетельство конкретного запуска. Транспортный prototype и unit fixture не считаются live-тестом.

Путь проверки: `ToolRegistry.execute` → нормализация/provenance → typed graph → повторное добавление без дублей → encrypted save → reopen. Не использовались пользовательские ключи или основной профиль.

[Поздний прогон 99/101](validation/v11/source-pipeline-release.json) · [прогон 100/101](validation/v11/source-pipeline-current.json) · [первый прогон 100/101](validation/v11/source-pipeline.json). Повторить командой `.venv/Scripts/python.exe -X utf8 scripts/verify_public_sources_v11.py --output NEW_PRIVATE_QA_DIR`.

Шесть существующих источников дали свежие результаты с сохранением и повторным открытием графа в отдельном прогоне. Это GitHub, Hacker News, Open Library, Wikimedia, GLEIF и Crossref. Вместе с 99 новыми это 105 отдельных подтверждений в двух поздних backend-прогонах. Локальные вычисления, пустые ответы, агрегирующие workflow и ошибки в счёт не включены.
