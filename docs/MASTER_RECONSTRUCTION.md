## Stage 1: воспроизведение причин

`scripts/qa_reconstruction_baseline.py`, реальные результаты сохраняются только в
исключённом из Git `output/reconstruction/baseline`.

1. **GEOINT, реальные пиксели:** найден оригинальный `Downloads/images.jpg`,
   547 × 365. Изображение прочитано локально, внешняя отправка отсутствует.
   Metadata complete; OCR partial; GeoCLIP и Waypoint complete. Первый GeoCLIP
   кандидат: 55.753437, 37.621559; Waypoint: 55.759551, 37.627003.
   `visual_models/pipeline.py` сопоставляет координаты, но не содержит captioning,
   поиска эталонов или проверки ориентиров. В модели отсутствует описание сцены.
   Изображение и результаты не включаются в Git.
2. **TON / агент:** повторяющийся вызов воспроизведён контролируемой локальной
   orchestration fixture, без API. После no_progress финальная языковая генерация
   не вызывается. `AgentRunner.run` напрямую переходит к `stop_report`: первые
   12 записей, сырые evidence ID, без агрегации транзакций. Это подтверждает
   механизм пользовательского дефекта; fixture не выдана за live TON-тест.
   Реальный TON live и проверка конечного ответа обязательны последующими этапами.
3. **Граф, реальная публичная страница:** штатный PublicPageReader прочитал
   `https://github.com/solvnox` с robots policy, статус complete. В links попали
   reporting abuse, Report abuse, GitHub status page, contact support.
   build(full=True) создал 8 publishes_link. PageParser исключает HTML nav/footer,
   но служебные GitHub ссылки находятся и в обычных div. Граф не требует
   происхождения из авторского контента, а body_sha256 ошибочно повышает статус
   любой ссылки до verified. Это не доказывает, что владелец публиковал эти URL.

Дополнительные причины: 1800 output tokens на агентный ход; finish_reason=length
не переносится в complete_turn metadata; обычный chat SSE имеет 2400 токенов без
продолжения. React Markdown заменяет все изображения текстовой заглушкой.

## Stage 2: анализ и финальный ответ

Добавлены отдельные normalization / analysis / correlation / synthesis / final
фазы. No-progress и исчерпание бюджета поиска завершают внешние запросы и передают
сохранённые результаты в synthesis. Её собственные защитные бюджеты по умолчанию:
65 536 output tokens и 300 секунд, на один запрос — до 8192 токенов в пределах
реального шлюза. Это отдельная управляемая фаза; количество абзацев не ограничено.
`finish_reason=length` продолжает тот же документ. Части и текущий draft находятся
в существующем зашифрованном checkpoint; Stop не запускает генерацию заново.
Обычная беседа не переведена на исследовательский механизм.

Локальная Decimal-агрегация вычисляется по всем возвращённым Gansar событиям до
пагинации карточек. TON alias канонизируется с CRC/workchain, testnet отделяется.
Считаются направления, объёмы по отдельным активам/контрактам, основные контрагенты,
крупнейшие операции, даты и неизвестные значения. Нераспознанные суммы не равны нулю.
Модель получает агрегаты и выборку фактов; полный сырой список транзакций ей не
передаётся. При ошибке провайдера формируется явно обозначенный локальный отчёт.

Вложения больше не дописывают системные инструкции в пользовательское сообщение.
Старые checkpoints читаются без перезаписи оригинального текста. В итоговых
ссылках ev-ID проверяются и скрываются за человеческим текстом. Прежний лимит
redaction в 16 000 символов больше не обрезает отчёт или потоковые события.

запись больше не стирает известный нулевой jetton-баланс, а token/NFT наблюдения
одного объекта объединяются с сохранением evidence и происхождения ключевых полей.

убрана; явно превышенный предел контекста даёт ошибку/fallback. Контекст компактно
выбирает источники контрагентов, сохраняя все аналитические категории. Перед текстом
