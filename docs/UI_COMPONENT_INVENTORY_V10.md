# V10 · Аудит общих компонентов

Базовый перечень всех компонентов и состояний сохранён в
[инвентаризации V9](UI_COMPONENT_INVENTORY_V9.md). V10 использует те же primitives,
а не отдельный набор controls для нового стиля графа.

| Семейство | Исправление / проверка V10 |
| --- | --- |
| Button, input, Select | GraphCommandBar объединяет поиск, сброс, тип, фильтры и раскладку. Общая высота, двухрядная компоновка на узком экране, доступные названия. Прямоугольники и горизонтальная обрезка измеряются в EXE. |
| Select / dropdown / radio | SearchableSelect сохраняет Radix portal, клавиатуру и collision positioning; поддерживает отдельную типизированную иконку опции. Сеть определяется по значению поля, а не подписи объекта. |
| Checkbox, switch, slider | Сохранены общие controls V9. Разделы настроек и фильтры проверяются нативно, disabled/mixed/read-only и клавиатура — frontend tests. |
| Details / disclosure | Только помеченные `dismissible` popup закрываются по Escape/клику снаружи; обычные раскрытые разделы не схлопываются. Клик в дочерний Radix portal не считается внешним. |
| Context menu | Воспроизведено перекрытие инспектором: меню было внутри нижнего stacking context renderer. Перенесено на общий слой GraphLayout; высота ограничена сценой, добавлены scroll, фокус, Arrow/Home/End, Escape и outside dismissal. Escape сначала закрывает меню, сохраняя fullscreen. |
| Toolbar / layout / clean | Общий grid GraphLayout распределяет header, command bar, инструментальную колонку, нижние controls и правый dock. Clean находится в header. Открытие dock пересчитывает safe zones миникарты без изменения камеры. |
| Inspector / results / resizer | Общий правый dock, прокрутка содержимого и согласованные ограничения ширины 260–480 px. Inspector и результаты могут быть открыты одновременно. При частичном ответе с длинной ошибкой прокручивается всё тело результатов: notice не отрезает gallery, выбор и добавление. |
| Graph cards / edges | Glass и Minimal используют общие данные и renderer с отдельными профилями материалов, плотности и связей. Компактный кошелёк сохраняет сеть и адрес, не повторяет адрес вместо дополнительной строки. |
| Lists / evidence / source details | Типизированные CryptoIcon применены в аналитическом индексе, результатах, inspector, источниках и каталоге Gansar. Остальные карточки, таблицы и provenance сохранены. |
| Dialog / tooltip / popover | Сохранены общие Radix реализации. Подмены native Windows file dialogs нет. В V10 измеряются открытые popup; основной dropdown не должен выходить за viewport. |
| Scrollbar / toast / notice | Сохранены глобальные стили; dock и длинные popup прокручиваются внутри доступной высоты. Итог вставки можно закрыть, он также скрывается через 9 секунд. |
| Appearance preview | Два варианта с миниатюрами и live preview, независимые настройки графа. Общие тема/акцент/обои сохраняются при переключении. |

Охват нативного обхода: все семь категорий настроек, поиск/сохранённые результаты,
Tree/Evidence, «Мой граф», инструменты и существующие release acceptance flows.
Основные controls присутствуют в чате, Canvas, истории и формах инструментов;
их общие реализации покрываются также существующими frontend/Python тестами.
Это не утверждение о переборе всех комбинаций всех экранов.

Итоговые количества проверок, снимки, масштабы и ограничения опубликованы в
[отчёте V10](UI_UX_RECONSTRUCTION_V10.md). Снимки с пользовательским локальным
пакетом логотипов остаются локальными; их контрольные суммы не заменяют
визуальную проверку.
