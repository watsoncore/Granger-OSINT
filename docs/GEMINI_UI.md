# Gemini и интерфейс GrangerPet 2.3

Результаты конкретной сборки, живого API, число тестов, SHA-256 и реальные снимки публикуются в [VALIDATION.md](../VALIDATION.md). Наличие SDK или поля ключа само по себе не доказывает успешный живой ответ.

## Одно состояние подключения

Панель создаёт один `AIState` и передаёт его настройкам и чату. Видимые состояния больше не вычисляются независимо из заполненного поля или локального `_ready`. Безопасный снимок содержит `provider`, `model_id`, `credential_available`, `configuration_saved`, `connection_status`, `last_error`, `last_verified_at`. Открытого ключа, его копии и сырого SDK-исключения в нём нет.

| Событие | Состояние |
|---|---|
| Провайдер/ключ не настроены | «ИИ не настроен»; черновик сообщения можно печатать, сеть не вызывается |
| Изменены поля подключения | Черновик; чат использует только ранее сохранённую конфигурацию |
| Настоящий тест черновика успешен | «Подключение проверено · Сохраните настройки» |
| Запись параметров и ключа подтверждена | Общая модель немедленно обновляет все окна; проверенная конфигурация получает «Подключено» |
| Сохранить без теста | Отправка доступна при наличии ключа, но статус «Настроено, не проверено» |
| Перезапуск | Сохранённые провайдер/модель/ключ обнаруживаются без автоматического API-теста |
| Сеть/квота/права/ошибка ключа | Отдельная причина; сохранённые параметры и история не удаляются |

`AIState.changed` обновляет обе поверхности. Проверки привязаны к поколению и конкретной конфигурации: старый ответ не подтверждает новый черновик. Проверка не сохраняет ошибочный ключ. «Готово» и закрытие с изменениями предлагают «Сохранить», «Не сохранять» или «Отмена». При отказе записи черновик остаётся, прежний ключ восстанавливается. Подробная причина старого расхождения и перезаписи независимым процессом: [AI_STATE_FIX.md](AI_STATE_FIX.md).

## SDK, модель и ключ

Используется официальный `google-genai`, закреплённый в `requirements.txt` на 2.33.0, и `python-dotenv` 1.2.4. Основная модель — `gemini-3.8-flash`, thinking по умолчанию `medium`; `minimal` не передаётся. Возможности и ID описаны в [документации модели Google](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash), вызов — в [GenerateContent API](https://ai.google.dev/api/generate-content) и [Python SDK](https://googleapis.github.io/python-genai/).

Приоритет ключа: пользовательский `gemini_api_key` Windows Credential Manager → переменная процесса `GEMINI_API_KEY` → `.env` в корне исходного проекта при локальной разработке. `.env.example` содержит пустое/примерное значение. Приложение не создаёт личный `.env` и не копирует в него реальный ключ. EXE env-файлы не читает; существующий `secret.env` также не является автоматическим источником. Персональные env-файлы исключены из Git, PyInstaller и исходного ZIP.

В форме показано наличие/источник ключа, а не его значение. Ввод скрыт, глаз раскрывает его только явным действием; при закрытии маска восстанавливается. Замена ключа после подтверждённого сохранения используется новым клиентом в следующем запросе. В обычный JSON записываются провайдер и ID модели, но не Gemini API-ключ. Секреты не входят в снимки общего состояния и отчёты QA.

## Разговор и типографика

Собственная компактная шапка и режимы «Поиск» / «Гермиона» сохраняют содержимое друг друга. Палитра разделяет окно `#17212B`, историю `#0E1621`, входящее сообщение `#182533`, исходящее `#2B5278`. Основной и разговорный текст — 14 логических px; заголовки 16–18 px, метаинформация 12–13 px. `Segoe UI Variable` используется при наличии, иначе `Segoe UI`; `ui_font` задаёт логический размер и сглаживание без веб-шрифтов.

История — последовательность настоящих выделяемых текстовых пузырей. Короткий текст получает естественную ширину, длинный — не более примерно 80% доступного места. Пользователь справа, Гермиона слева. HTML остаётся обычным текстом; блоки с тройными обратными кавычками локально оформляются моноширинным шрифтом. Контекстное меню копирует исходное сообщение целиком. Длинные URL и кириллица переносятся без горизонтального расширения разговора.

Composer начинается с 46 px и растёт до 122 px, далее прокручивается внутри. Enter отправляет один запрос, Shift+Enter добавляет строку. Временная ошибка не блокирует набор текста, посещение настроек не стирает черновик. Собственное сообщение появляется сразу; «Печатает…» существует только во время фактического ожидания. Ответ не имитируется таймером.

История и ограниченный контекст текущего разговора живут в памяти процесса. Отмена и закрытие панели прекращают ожидание и отбрасывают поздний ответ, сохраняя диалог. Ошибка показана отдельным компактным сообщением с ручным повтором. Новый запрос не наследует код ошибки прежнего запроса.

## Qt-переходы и прокрутка

`QVariantAnimation` / `QPropertyAnimation` дают короткое наведение, движение активного подчёркивания вкладки и появление нового сообщения. Появление пузыря длится 150 мс, opacity effect затем удаляется. При добавлении сотни сообщений одновременно остаётся не более одного такого эффекта.

Колесо и тачпад сохраняют обычное поведение Qt без искусственной инерции. Если пользователь уже находился в конце, 140-мс анимация следует за ответом. При чтении старых сообщений ответ не переносит пользователя вниз. Изменение размера пересчитывает переносы. `SPI_GETCLIENTAREAANIMATION` учитывается через `reduced_motion`: при выключенной анимации Windows переходы выполняются без эффектов.

## Явный анализ, ошибки и квоты

Обычный поиск, набор текста, открытие настроек или смена вкладки не отправляют сведения в Gemini. «Объяснить с помощью Гермионы» открывает выбор конкретных находок и уведомление об облаке. Подтверждённые факты предварительно отмечены, гипотезы требуют отдельного выбора. Передаются только выбранные данные, максимум 50 объектов, со статусами и ссылками.

Приватные поля, ключи, сессии, скрытая диагностика и локальные файлы не добавляются. Данные источников недоверенные; они не могут менять системную инструкцию или запускать действия. Модели не предоставлены инструменты приложения, автоматический function calling отключён. ИИ не изменяет SearchResult, не выдумывает отсутствующую атрибуцию и не объединяет людей только по нику или регистрации email.

SDK выполняет одну попытку (`HttpRetryOptions(attempts=1)`). При 429 учитываются Retry-After / RetryInfo: ранний повтор не создаёт HTTP-запрос, соответствующая кнопка временно недоступна. Общие 5 RPM/20 RPD не зашиты. Раздельно обработаны отсутствие ключа, 401/403, 404, 429, временная 503/сеть, таймаут, пустой/некорректный/заблокированный ответ и отмена. Конфигурация при временной ошибке сохраняется. Локальная Ollama остаётся доступной с прежним ограничением на установленные локальные модели loopback-сервера.

## Основные файлы

| Файл | Назначение |
|---|---|
| `ai_state.py` | Общая безопасная модель черновика, сохранённой конфигурации и API |
| `connections.py`, `settings_dialog.py` | Проверка, запись, сброс черновика, маска и предупреждение о несохранённом |
| `chat.py`, `message_view.py` | Composer, пузыри, worker, выбор находок и прокрутка |
| `panel.py`, `window_chrome.py`, `result_view.py` | Шапка, вкладки, компактная выдача и действия возле находок |
| `typography.py`, `theme.py`, `motion.py` | Системный шрифт, палитра и короткие переходы |
| `pet.py`, `launcher.py`, `app.py` | Сохранение собственных полей поверх последней конфигурации и безопасный IPC |
| `ai.py`, `ai_keys.py` | Официальный SDK, история, ошибки, приватность и ключ |

Автоматические проверки используют явно обозначенные фикстуры и код настоящего SDK с `httpx.MockTransport`. Это не живой ответ Google. Доступность реального API подтверждает только отдельный фактический запрос; окончательный исход записывается в [VALIDATION.md](../VALIDATION.md).
