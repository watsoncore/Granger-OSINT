# Инструменты Master Fix V2

В текущем каталоге 75 зарегистрированных операций. При проверке без пользовательских ключей 70 вернули available. Это число включает локальные вычисления, чтение доказательств, поиск по каталогу и адаптеры с ещё не проверенной сетью. Непосредственно перед модернизацией реестр содержал 70 операций. [Машинная матрица](validation/master-fix-v2/tools-integration-audit.json)

При этом тесте недоступны username_snoop, vk_authorized, hash_virustotal, image_reverse_search и nuclei_check. Пользовательский диалог DeepSeek использует отдельный защищённый ключ. Публичные GeoIP, TikTok oEmbed, Steam Community, SRTM и OpenHistoricalMap работают без личных ключей.

Для каждой операции матрица хранит manifest, схему, ограничения и результаты вызовов из перечисленных контрольных расследований. Пустой массив результатов означает, что данный прогон не подтверждает выполнение этой операции. Одна выборка источника может содержать много предметов или документов.

При обходе найдено 12 архивов, 13 верхнеуровневых каталогов проектов и четыре вложенных компонента. В матрице для ранее добавленных поставок указаны лицензии, зависимости, методы, необходимость авторизации, риски и статус интеграции. Из поставок этой группы в приложение включено проверенное подмножество SteamRecon MIT. У двух архивов аудит не обнаружил лицензии. Остальные специализированные возможности реализованы штатными адаптерами либо остаются отключёнными. [Инвентаризация](NEW_TOOLS_AUDIT.md), [проверка существующих локальных адаптеров](INTEGRATIONS_CORE.md), [ABI и ограничения источников](INTEGRATIONS.md)

Матрица также содержит 13 существующих локальных исходных каталогов с фактическими методами, группами зависимостей и SHA файлов лицензий. Для Blackbird учтена вложенная GPL-3.0 `docs/LICENSE`, для Snoop — отдельные условия личного использования `COPYRIGHT`; поверхностный поиск root LICENSE их пропускал. Vkbottle не вызывается. У Gansar не найден файл лицензии; его неизменённые пользовательские исходники остаются внешними, в ZIP они не включаются.
