# GrangerPet

GrangerPet 2.6 — настольная Chibi-Гермиона, автономные OSINT-исследования DeepSeek, чтение публичных страниц и локальный анализ Ollama для Windows x64. Интерфейс написан на Python и PySide6; персонаж работает в отдельном процессе с прозрачным окном поверх рабочего стола.

## Запуск

Готовая сборка: `dist/GrangerPet.exe`. Дважды щёлкните файл и нажмите **«Запустить Гермиону»**. Для запуска EXE, персонажа и базового Google-поиска Python и API-ключи не нужны. Необязательные локальные движки используют существующие исходники и собственные изолированные окружения; их подготовка описана ниже.

- Короткий щелчок по фигурке открывает или скрывает панель поиска и вызывает краткое смущение.
- Перетаскивание перемещает персонажа; положение сохраняется.
- Захват около воротника включает инерцию. Резкое движение вверх поджимает ноги и вытягивает тело, вниз — сжимает тело; появляется сердитая мимика. Медленное перемещение не вызывает сердитую реакцию.
- Правая кнопка открывает меню персонажа.
- В Launcher регулируются размер, частота анимации и реакция на курсор.
- Размер ограничен диапазоном 100–195 px, стандартное значение — 195 px.
- Закрытие окна Launcher оставляет персонажа на рабочем столе. Кнопка выхода завершает приложение вместе с персонажем.
- Повторный запуск использует существующий экземпляр. Состояние в Launcher проверяется через локальное межпроцессное соединение.

## Поиск

Главное окно открывается размером **760×690 логических пикселей** и изменяется мышью до минимума 460×420. За шапку можно переместить окно; кнопки позволяют свернуть, развернуть и восстановить его. Двойной щелчок по шапке переключает развёрнутый режим. **F11** включает настоящий fullscreen и возвращает прежний оконный/развёрнутый режим, **Esc** выходит из fullscreen. Персонаж остаётся отдельным окном поверх рабочего стола.

Интерфейс использует системную типографику и спокойную палитру настольного мессенджера. Внутри доступны **«Поиск»** и **«Гермиона»**; Canvas открывается как отдельное пространство документа в том же окне. Переключение не уничтожает переписку, документ и найденные сведения.

Введите запрос и нажмите Enter или **«Найти»**. Во время выполнения эта же кнопка становится **«Остановить»**. Запоздалые события отменённого поиска не попадают в новый запрос. Основное место занимает список, служебные ошибки раскрываются отдельно.

Тип данных определяется локальными проверками без ИИ. Под строкой показаны направление и источник. Для неоднозначного `solvnox` сначала выберите **«Публичные профили»** или **«Упоминания»**; выбор относится только к текущему запросу.

| Запрос | Направление |
|---|---|
| Никнейм → «Публичные профили» | Один готовый основной движок: Maigret с резервным выбором Blackbird/Social Analyzer; Snoop требует включения в настройках |
| TON `EQ…`, `UQ…`, `0:<64 hex>` | Локальная проверка структуры и CRC, затем существующий аналитический движок Gansar |
| Email | Проверка синтаксиса и домена, Holehe |
| Международный телефон, включая `+7` | Проверка плана нумерации, PhoneInfoga |
| Публичные ссылки Telegram, VK, Instagram | Telethon, vk_api, Instaloader соответственно |
| HTTP(S)-ссылка или однозначный домен | WaybackPy |
| «Упоминания» или Google Dork | Google API либо браузер |

TON testnet и TON DNS не направляются к mainnet-провайдерам: текущий путь интеграции их не поддерживает и сообщает причину. Gansar выполняется внутри внешнего рабочего процесса без собственного окна и графа. Стадии анализа выводятся из настоящих событий ядра.

Находки появляются по мере получения. Одинаковые URL объединяются; статусы выполнения и ошибки источников находятся в отдельной сворачиваемой диагностике. **«Найдено»** считает уникальные объекты, подтверждённые правилом источника; сомнительные наблюдения отмечаются отдельно. Подтверждение профиля источником не устанавливает личность его владельца.

Выдача зависит от вида сведений. Email показывается короткими строками с названием сервиса и действительным статусом, без повторения адреса и длинного предупреждения в каждой строке. Публичный профиль содержит платформу, имя и URL; действие открытия доступно рядом с ним. Для TON есть сводка адреса и наблюдений, атрибуция с её достоверностью и выбор реально заполненных групп фактов. Клик на строку открывает подробности с полными значениями и копированием отдельных полей. Ссылка на личный профиль не выдумывается, если email-источник вернул только страницу сервиса. Список остаётся виртуализированным: отдельный QWidget на каждую находку не создаётся.

Настройки открываются **шестерёнкой в отдельном окне**: вкладки «Источники», «Авторизация», «ИИ» и «Поиск». Поля токенов и сессий не занимают область выдачи. Кнопка проверки готовности действительно запускает изолированные мосты и импортирует зависимости; наличие папки не означает рабочее подключение. Авторизация Telegram/VK и других сервисов проверяется отдельно от доступности локального инструмента.

**«Операторы Google»** открывают отдельный конструктор. Он поддерживает `site:`, `filetype:`, `intitle:`, `inurl:`, `intext:`, точные фразы и исключение слов. Перед запуском виден итоговый запрос.

Без поискового API приложение открывает сформированный запрос в Google через браузер по умолчанию. Список настоящих результатов при этом доступен в браузере; внутри панели показывается соответствующее пояснение. Запросы не выдаются за найденные страницы, вымышленной выдачи нет.

Для встроенной выдачи откройте настройки через шестерёнку и укажите действующий ключ **Google Custom Search JSON API** и идентификатор поисковой системы **cx**. Доступность API и квоты определяются вашей учётной записью Google. Приложение использует официальный HTTPS endpoint `https://www.googleapis.com/customsearch/v1`; оно не обходит CAPTCHA и ограничения Google. При ошибках API отображается причина. Полученные карточки содержат название, URL, доступное описание и исходный запрос; источник можно открыть, URL — скопировать.

Актуальные условия подключения и сроки доступности API смотрите в [официальной документации Google](https://developers.google.com/custom-search/v1/overview). Режим через браузер доступен независимо от возможности подключить API.

Настройки сохраняются в `%APPDATA%\GrangerPet\settings.json`, журналы — в `%APPDATA%\GrangerPet\logs`. Ключи и токены подключений хранятся отдельно в защищённом Windows-хранилище; они не включаются в исходники и EXE.

## Подключение локальных источников

Все уже загруженные исходники остаются в проекте. Для подготовки независимых окружений:

```powershell
python scripts/setup_sources.py --audit
python scripts/setup_sources.py --groups all
```

Скрипт использует существующие папки и Python 3.12; при наличии `uv` интерпретатор подготавливается автоматически. Репозитории повторно не клонируются. Источники ищутся рядом с EXE/в родительской папке или по выбранному пути в настройках. Gansar работает через собственный внутренний analyzer, без отдельного интерфейса и экспорта графов. Веб-архив использует настоящий WaybackPy, платформенные адаптеры — Instaloader, Telethon и один VK API wrapper.

Подробные зависимости, авторизация и лицензии: [docs/INTEGRATIONS.md](docs/INTEGRATIONS.md), [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Правила маршрутизации, причина прежней ошибки выдачи и результаты настоящих сетевых проверок: [docs/ROUTING_REPORT.md](docs/ROUTING_REPORT.md). Окружения ссылаются на подготовленный интерпретатор; для другого компьютера требуется повторная подготовка внешних движков. Основной EXE остаётся автономным.

## Переписка, Markdown и Canvas

В чате сообщения пользователя и Гермионы различаются стороной и цветом пузыря. Ширина длинного ответа ограничена для чтения даже на развёрнутом экране. Поле ввода расширяется по мере набора; Enter отправляет, Shift+Enter вставляет строку. Текст можно выделять и копировать. Новые ответы прокручивают историю вниз только тогда, когда читатель уже находится внизу.

Ответы Гермионы поддерживают заголовки, жирный/курсивный текст, вложенные списки, цитаты, разделители, ссылки, inline-code, блоки кода и Markdown-таблицы. Широкие таблицы допускают горизонтальную прокрутку. Блоки кода можно копировать отдельным действием, а исходный Markdown — через контекстное меню. Потоковый ответ обновляет тот же пузырь; незавершённая разметка не создаёт второе сообщение. HTML, JavaScript, встроенные изображения и автоматическая загрузка ресурсов не исполняются; поддержанные внешние ссылки открываются только по щелчку.

У длинного ответа Гермионы появляется **«Открыть в Canvas»**. Это рабочий документ с оглавлением по заголовкам, Markdown-просмотром, выделением и копированием. **«Править»** открывает исходный текст; **«Сохранить»** сохраняет локальную копию, **«Экспорт .md»** записывает Markdown в выбранный файл. Изменения также сохраняются с короткой задержкой после ввода. **«К чату»** возвращает переписку, сохраняя документ. Правки Canvas не меняют исходное сообщение и журнал доказательств.

Документы Canvas находятся в `%APPDATA%/GrangerPet/canvas/`, журналы свидетельств — в `investigations/`. Это отдельные локальные Markdown/JSON-файлы; DPAPI-защита переписки не означает шифрование экспортированного пользователем документа. Перед передачей результатов в модель исключаются ключи, сессии и внутренняя диагностика.

## DeepSeek V4 Flash и Ollama

Откройте **шестерёнку → «ИИ»**, выберите **DeepSeek V4 Flash** и модель **`deepseek-v4-flash`**. Подключение использует OpenAI-compatible Chat Completions API шлюза **`https://api.aikeysforyou.com/v1`**, а не сервер OpenAI или прямой API DeepSeek. Введите собственный ключ этого шлюза. Ключи Google не подходят и автоматически не переносятся.

**«Проверить подключение»** делает настоящий запрос с введённым ключом и расходует баланс шлюза. Успешная проверка черновика означает **«Подключение проверено · Сохраните настройки»**. Нажмите **«Сохранить»**: после подтверждённой записи провайдера, ID модели и ключа настройки и существующий чат сразу получают общее состояние. Автоматического сетевого теста при запуске, открытии настроек или вводе текста нет.

Ключ хранится в Windows Credential Manager и не попадает в обычный JSON. Поле скрыто; после закрытия и повторного открытия маска восстанавливается. При отказе записи черновик остаётся, ложное «Подключено» не появляется. **«Готово»** и закрытие несохранённой формы предлагают сохранить, отказаться или продолжить редактирование. Замена ключа применяется к следующему клиенту без перезапуска.

После перезапуска сохранённые провайдер, модель и доступный ключ разрешают отправку. До настоящего успешного ответа в текущем процессе статус — **«Настроено, не проверено»**. Ошибки 401 (ключ), 402 (оплата/баланс), 403 (доступ), 429 (лимит), тайм-аут и недоступность сервера показываются отдельно и не стирают конфигурацию или диалог. `Retry-After` задерживает ранний ручной повтор; автоматических повторов нет.

В режиме **«Гермиона»** используются прежние пузыри и поле ввода. Enter отправляет один запрос, Shift+Enter вставляет строку. Обмен выполняется в рабочем потоке с отменой, интерфейс остаётся отзывчивым. Текущие реплики и контекст сохраняются локально в `chat-history.dpapi`, защищённом DPAPI текущего пользователя Windows, и восстанавливаются после перезапуска. Архив ограничен последними 300 сообщениями и 24 репликами контекста; при большом объёме сохраняется меньший набор последних полных сообщений. Ключ не является частью переписки и перед записью дополнительно скрывается. При недоступности защищённого хранилища текущая переписка остаётся в памяти. Последующие запросы содержат успешные предыдущие реплики. Черновик, сообщения и результаты поиска сохраняются при смене вкладок и посещении настроек.

Гермиона — стилизованный ИИ-помощник в образе вымышленного персонажа, а не реальная Эмма Уотсон или другой человек. Она помогает с OSINT естественным русским языком, отделяет факты от гипотез и не превращает каждую реплику в ролевую сцену. Все запросы JSON передаются в UTF-8.

**«Объяснить с помощью Гермионы»** сохраняет прежний механизм: пользователь выбирает реальные находки и явно отправляет их в облако. Изначально отмечены только подтверждённые объекты, максимум — 50; ключи, сессии и скрытая диагностика не передаются. Ответ не изменяет исходную выдачу. Ручной запуск поисковых инструментов остаётся прежним.

Явная просьба «Найди публичные упоминания никнейма solvnox» запускает расследование прямо в чате. DeepSeek выбирает инструменты, получает настоящие результаты, выбирает релевантные URL и читает доступные страницы через `web_read`. Прочитанный текст, заголовки, метаданные, JSON-LD/Open Graph, таблицы и связанные ссылки могут стать основой следующего шага. Поисковый сниппет и текст, непосредственно полученный со страницы, отмечаются как разные виды свидетельств. URL, инструмент, время и `evidence_id` сохраняются отдельно от пересказа модели.

По умолчанию расследование ограничено **10 ходами, 14 вызовами, 240 секундами и 48 000 учитываемых токенов**; параллельно работают не более двух инструментов. В **Настройки → Поиск → Бюджет расследования** можно изменить пределы. Для чтения страниц стандартны **6 страниц и глубина 2**, допустимы 1–12 страниц и глубина 0–3. Бюджет применяется к новому расследованию; увеличение может расходовать больше времени и баланса шлюза. Стоп в прежнем поле ввода отменяет продолжение, а уже полученные свидетельства сохраняются.

`web_read` открывает только URL, обнаруженные разрешённым инструментом, ссылки с уже прочитанных страниц либо URL, явно указанные пользователем. Схемы и адреса проверяются; localhost, частные и служебные сети, опасные порты и URL с секретами запрещены. DNS проверяется на каждом переходе, соединение привязано к разрешённому публичному IP, имя TLS проверяется. Защита сайта, CAPTCHA, авторизация и paywall не обходятся. JavaScript не исполняется: если обычный HTTP не раскрывает нужные данные, агент сообщает ограничение. Подробности — [docs/MASTER_UPGRADE.md](docs/MASTER_UPGRADE.md).

Приложение не читает DeepSeek-ключ из старых Gemini-настроек, переменных окружения или env-файлов. Существующий старый секрет не удаляется и не отправляется новому шлюзу. После обновления прежний облачный провайдер заменяется на DeepSeek с новой моделью; для его использования нужно самостоятельно ввести новый ключ.

Существующая локальная Ollama сохраняется по адресу `http://localhost:11434`; можно выбрать установленную модель. Модели не скачиваются автоматически. Базовый поиск работает без ИИ. Исторические материалы прежней интеграции Gemini сохранены в документации как описание старых версий и не являются инструкцией активного подключения.

## Исходный код

Для разработки требуется Windows x64, Python 3.14 и зависимости из `requirements-dev.txt`:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe main.py
```

Основные модули находятся в `grangerpet/`: Launcher, управление процессами и настройками, окно персонажа, состояния анимации, OSINT-панель и конструктор запросов. Графика и описание анимаций включены в `grangerpet/assets/`.

## Графика и анимации

Текущий образ адаптирован из предоставленного пользователем рисунка Chibi-Гермионы с палочкой. ImageGen подготовил полный силуэт и прозрачный фон с сохранением лица, чёлки, волнистых волос, палочки и одежды. Мастер и исходный референс находятся в `resources/wand-reference/`, рабочий базовый PNG — `grangerpet/assets/character.png`.

Последовательности **Idle, Hover, Happy, Thinking, Working, Walk и Error** воспроизводимо создаёт `scripts/create_wand_animations.py` из этого же мастера. Дыхание и периодическое моргание встроены в Idle; движения глаз, рук с палочкой и ног меняются по состоянию. Это настоящие последовательности прозрачных кадров, не фильтр пикселизации и не один масштабируемый рисунок. Пропорции и точки захвата/взгляда записаны в `animations.json`, чтобы механика соответствовала новой фигуре.

Происхождение и способ адаптации описаны в `grangerpet/assets/provenance.json`. Предыдущие ресурсы сохранены в `resources/pre-wand-assets/`; прежние генераторы относятся к прежней внешности и не должны запускаться поверх новых ресурсов. Авторство предоставленного референса не приписывается приложению.

Переработка поиска сохраняет эти 249 кадров. Краткие реакции при захвате и щелчке накладываются во время отрисовки: они не перезапускают поиск и после таймера возвращаются к текущей основной анимации. Скорость измеряется по окну нескольких событий в логических пикселях Qt; одиночный скачок координат не считается рывком. Диагностическая трассировка по умолчанию выключена.

## Самостоятельные занятия Гермионы

После периода бездействия Гермиона иногда раскрывает книгу и перелистывает страницу, выполняет короткое заклинание, зевает и засыпает. Редкий шуточный вариант заклинания «Авада Кедавра» имеет зелёный визуальный эффект и длительный cooldown; он ни на что в системе не воздействует. Возможны короткий уход за край экрана и самостоятельное возвращение с анимированным шагом.

Действия строятся из прежних кадров и локально рисуемых 2D-реквизита/эффектов: внешность, одежда и исходные спрайты не заменены. Чтение и сон сохраняют небольшие движения; сон использует настоящие кадры с закрытыми глазами. Случайные интервалы и длительности не образуют механический повтор. Действия прерываются пользовательским вводом, приближением курсора, перетаскиванием и работой чата/агента. Открытое основное окно и активное расследование не запускают временный уход. После ухода возвращается прежняя позиция; внеэкранная координата не записывается как домашняя. Автономные действия не запускают сеть или OSINT-проверки.

## Сборка EXE

```powershell
.\build.ps1
```

Скрипт создаёт `.venv`, устанавливает закреплённые версии зависимостей, проверяет прозрачность и разные кадры семи анимаций, запускает тесты и собирает `dist/GrangerPet.exe` через PyInstaller. После сборки он запускает сам EXE в обычном режиме и с персонажем: из пустой папки, с новым профилем и без Python/Qt в PATH. Проверяются код завершения, новые журналы запуска и формат AMD64 Windows GUI. Отчёт с SHA-256 записывается в `dist/binarysmoke.json`. Перед сборкой закройте запущенные экземпляры GrangerPet; существующий экземпляр считается препятствием проверке. Параметр `-Python` позволяет задать путь к Python 3.14; `-SkipTests` пропускает модульные тесты, но сохраняет проверку готового EXE.

Ручная сборка после установки зависимостей:

```powershell
.\.venv\Scripts\python.exe scripts/verify_assets.py
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean GrangerPet.spec
.\.venv\Scripts\python.exe scripts/smoke_exe.py
```

В `.github/workflows/build-windows.yml` настроена сборка на Windows runner. После отправки проекта в GitHub workflow можно запустить вручную; результат появится в артефакте **GrangerPet-Windows-x64**. Настройка workflow сама по себе не означает, что удалённая сборка была выполнена.

EXE собирается без консольного окна и включает Qt, графические ресурсы и HTTP-клиент для OpenAI-compatible API. Gemini SDK не входит в активную интеграцию. Личный `.env`, `secret.env` и пользовательское хранилище секретов в пакет не входят. На первом запуске однофайловая сборка распаковывает зависимости, поэтому запуск может занимать несколько секунд.

## Проверка

Автоматические проверки запускаются командой `python -m pytest -q`; проверка графики — `python scripts/verify_assets.py`; запуск готового EXE — `python scripts/smoke_exe.py`. Проверяемый файл, SHA-256 и результаты двух запусков находятся в `dist/binarysmoke.json`. Итоговый отчёт конкретной сборки, ограничения и фактическая публикация — [VALIDATION.md](VALIDATION.md), архитектура версии 2.6 — [docs/MASTER_UPGRADE.md](docs/MASTER_UPGRADE.md), активная интеграция ИИ — [docs/DEEPSEEK.md](docs/DEEPSEEK.md); предыдущая переработка маршрутизации описана в [docs/SEARCH_OVERHAUL.md](docs/SEARCH_OVERHAUL.md).

`scripts/qa_overhaul.py` проверяет компоновку и виртуальный список с явно обозначенными тестовыми данными. `scripts/qa_native_input.py` проверяет окно персонажа в Windows настоящими системными событиями `SendInput`, со свежим профилем и проверкой PID/HWND; он временно перемещает курсор и восстанавливает его после проверки. Это отдельная инженерная проверка событий ОС, а не имитация ручной оценки человеком. `scripts/verify_router_live.py` отдельно выполняет ограниченные настоящие сетевые поиски. Эти скрипты не запускаются при обычном использовании приложения.

Живые запросы к Google Search API, шлюзу DeepSeek и авторизованным аккаунтам требуют действующих настроек и отдельной проверки. Зелёные fixture-тесты не подтверждают доступ к внешнему аккаунту.

Фанатский независимый проект. GrangerPet не является официальным продуктом правообладателей Harry Potter, Google или OpenAI.
