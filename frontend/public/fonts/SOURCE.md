- Size:164700bytes;742glyphs.

The TrueType cmap was checked locally for all Russian letters U+0410–U+044F and U+0401/U+0451. All are covered. The source metadata lists Cyrillic and Cyrillic Extended. The original variable font is kept intact, not subset or renamed.

Comparison: Inter's official project documents strong small-text design and OFL1.1 licensing; Manrope was selected for a slightly more substantial, compact Cyrillic rhythm consistent with the existing dark interface. Geist's currently published primary specimen did not provide sufficient evidence of complete Russian support for this selection. This is not a claim that every Geist release lacks Cyrillic.

Production uses this bundled file through `@font-face`. No Google Fonts or other network request occurs when the app runs. Native Windows WebEngine screenshots and `document.fonts` checks validate the actual renderer separately.
